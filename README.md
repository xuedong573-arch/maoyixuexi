开课前读取状态卡和进度；按当前P课讲授。收录新日报不自动验收，临时插问不自动换课。根据真实提交更新进度和状态卡，结构改变另记更新日志。

旧待交作业按能力映射到新案例，不逐项追缴或作为重学全部基础的理由。保留历史通过记录，不将新课未验收数当知识清零。
