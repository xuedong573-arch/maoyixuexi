# 大宗商品贸易学习档案

这是“大宗商品贸易 + 氧化铝现货与期货”长期课程的唯一课程存档点。

## 文件说明

- [课程总纲](docs/course-syllabus.md)：课程目标、30 天路线、教学规则与边界。除非学员明确要求调整，否则主线以此为准。
- [学习进度表](docs/progress.md)：按 Day 记录状态、掌握度、薄弱点、作业和下一步。每次结课后更新。
- [课程状态卡](docs/status-card.md)：一页内的最新状态。每次开课前先读取，用于跨聊天快速恢复。
- [更新日志](CHANGELOG.md)：记录课程结构或规则的重大调整；普通学习进度不在这里重复记录。

## 权威顺序

发生信息冲突时，按以下顺序判断：

1. 学员最新的明确要求；
2. `docs/status-card.md` 的当前进度；
3. `docs/progress.md` 的历史学习记录；
4. `docs/course-syllabus.md` 的课程结构；
5. 聊天记录。

## 固定更新流程

每次正式学习：

1. 开课前读取状态卡和进度表；
2. 按总纲推进当前 Day，不因临时插问擅自跳课；
3. 结课后更新进度表；
4. 同步刷新状态卡；
5. 只有课程目标、结构、节奏或规则改变时，才更新总纲与更新日志。
