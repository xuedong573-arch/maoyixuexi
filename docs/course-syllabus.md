# 大宗商品贸易业务进阶课程｜10课精简版 v2.1

> 更新日期：2026-10-22  
> 最新要求：在六个业务模块内，将原30课压缩到10课以内；基础不重复，难度与深度提高一级。  
> 当前：10课路线已就绪，P01待开课；本次仅调整计划，未讲授或验收。  
> 形式：10节综合课，每课约2小时核心学习，加30分钟文华/头寸核对；合计约25小时，可分段完成。

## 1. 压缩原则

以采购、供应商授信、采购签订执行与款货票、库存及头寸、客户授信、销售为主线。前9节各解决一组相互衔接的业务问题，第10节完成综合评审。

压缩依靠合并重复讲解和同一流程内的练习、提供已填好基础字段的案例资料、减少独立作业。每课最多三个重点、一份主要输出、三个费曼问答；不把原30节内容全部堆入10节，也不拆出额外必修子课。

已接触的报价、基差、开平仓、货权、物流、保证金和资金成本直接用于案例。出现关键错误时，用5—10分钟定点回补并替换当课部分练习，不重开基础章节。旧任务按能力映射检验，历史成绩保留，不逐项追缴。

课程提升到：能判断条件、读业务凭证、算关键数量金额、提出执行建议并处理一两个异常。复杂授信模型、财报审计、特殊税务处理、详细期转现/交割规则、复杂跨期策略和长约特殊谈判，改为有需要时查阅的资料，不另设必修课。期权仍不安排。

## 2. 10节课表

| 课次 | 主题 | 三个学习重点 | 主要输出 |
|---|---|---|---|
| P01 | 采购决策：买不买、买多少、什么条件买 | 统一报价与成本口径；确定采购上限和首批量；形成带条件的谈判方案 | 一页采购立项建议 |
| P02 | 供应商准入与授信 | 核主体、货源及履约能力；从简版财务看现金压力；核预付款风险额度和释放条件 | 供应商信用与付款条件意见 |
| P03 | 采购合同与付款安排 | 检查两端数量、质量、定价和交期匹配；设计保证金、分批付款与尾款抵扣；明确变更及付款依据 | 合同审阅与逐批付款计划 |
| P04 | 采购执行：提货、验收与异常 | 确认可提货及提货授权；跟踪两个工厂的分批执行；处理数量、质量和延期差异 | 提货执行与异常跟踪记录 |
| P05 | 采购结算：款、货、票核对 | 按合同与批次串起交付、收付及发票；核尾差退款和保证金余额；判断结单或继续跟踪 | 采购款货票对账及未结事项表 |
| P06 | 库存管理：可售、可交付与库龄 | 核在库、在途、货权及限制；扣除已售预留并按时间判断可交付；安排库龄和短缺处理 | 库存与交付安排表 |
| P07 | 头寸管理：定价、套保与移仓 | 识别采购销售两端的价格风险；核方向、数量、月份和实际成交；完成一次后点价移仓联动核对 | 现货定价与期货头寸核对表 |
| P08 | 客户授信：账期、额度与放货 | 核客户需求与回款来源；按政策算订单预占、应收、回款和可用额度；处理超额/逾期及复审 | 客户授信与分批放货意见 |
| P09 | 销售管理：报价到回款 | 结合库存、成本和客户条件形成报价；衔接销售合同、点价与交付；跟踪收款、开票和尾差结清 | 销售执行与回款方案 |
| P10 | 综合实战：一采一销全业务复盘 | 串起两端信用与合同执行；核款货票、库存和期现损益；区分利润、资金峰值与未结风险 | 一份完整业务复盘及改进意见 |

模块分配：采购1节；供应商授信1节；采购管理3节；库存及头寸2节；客户授信1节；销售1节；综合复盘1节，共10节。

这是教学顺序。实际立项时就同时考虑客户需求、上下游信用、销售条件与资金，不把相关审核推迟到货物采购之后。

## 3. 各课的案例与通过标准

### P01 采购决策：买不买、买多少、什么条件买

- 案例：低价高预付与高价短账期两种货源，结合下游需求选方案；加入一次交期延后。
- 本课输出：一页采购立项建议。
- 通过标准：说明采购上限、数量、利润来源和资金/交付条件，不把意向订单视为已落实销量。

### P02 供应商准入与授信

- 案例：同一供应商有两笔预付款和一笔退款未到账，判断新单能否继续付款。
- 本课输出：供应商信用与付款条件意见。
- 通过标准：分清我方向供方预付的风险与供方给我方账期；按题目政策核占用、期限和附加条件。

### P03 采购合同与付款安排

- 案例：3000吨合同设置10%业务保证金冲抵尾款，核累计支付和待付余额。
- 本课输出：合同审阅与逐批付款计划。
- 通过标准：找出关键条款缺口，避免保证金重复抵扣；每笔付款有条件、有凭证、有授权依据。

### P04 采购执行：提货、验收与异常

- 案例：2000吨/1000吨分厂提货，其中一批启动受阻；再给出一项磅差或验收差异。
- 本课输出：提货执行与异常跟踪记录。
- 通过标准：分清计划、实提、验收和结算量；异常写明证据、责任、下一动作和处理期限。

### P05 采购结算：款、货、票核对

- 案例：货已提完但发票未齐、保证金未抵完或退款未到账，核哪些事项仍未结束。
- 本课输出：采购款货票对账及未结事项表。
- 通过标准：数量金额可勾稽，暂估与最终分开；阶段差异有解释，不能仅凭提货完成就结单。

### P06 库存管理：可售、可交付与库龄

- 案例：同一批货有已售预留、在途和待验量，判断还能承诺多少以及何时能交。
- 本课输出：库存与交付安排表。
- 通过标准：不重复承诺货物，不把所有在库/在途量算作立即可售；直送记录真实去向。

### P07 头寸管理：定价、套保与移仓

- 案例：在同一张表上依次记录采购定价、销售部分点价和剩余量移仓，并核追加保证金需求。
- 本课输出：现货定价与期货头寸核对表。
- 通过标准：区分库存与价格敞口、委托与成交；旧仓平和新仓开分别核算，月差影响不重复计入。

### P08 客户授信：账期、额度与放货

- 案例：客户尚有额度但出现逾期，要求继续提货；在给定授权政策下提出可执行方案。
- 本课输出：客户授信与分批放货意见。
- 通过标准：额度够不自动放货；明确期限、放货条件、升级审批和恢复信用条件。

### P09 销售管理：报价到回款

- 案例：给同一客户比较现款与账期报价，再处理分批点价、自提签收和最终结算。
- 本课输出：销售执行与回款方案。
- 通过标准：报价有可执行依据，点价和已有头寸相符，放货有授权，回款与发票分别核清。

### P10 综合实战：一采一销全业务复盘

- 案例：汇总前9节连续案例，加入客户回款延迟或期货保证金追加中的一项，评审后续能否执行。
- 本课输出：一份完整业务复盘及改进意见。
- 通过标准：给出可追溯的数量/金额/定价记录，解释利润与现金差异，明确未结事项及下一步。


每课三个费曼问题围绕：你作什么决定；依据哪些数据和凭证；其中一个条件变化后如何调整。每个问题可先口述，再补必要计算。

P05检查采购执行与结单，P07检查库存与头寸联动，P10作最终综合检查。其他课在各自输出中完成检验，不再额外安排模块考核课。

## 4. 一条连续业务案例

使用明确标为模拟的3000吨氧化铝采购机会，计划涉及两个工厂2000吨/1000吨、10%业务保证金、分批提货和不同客户付款/点价需求。

初始是待评估机会，不预设已采购、已付款或已获批准。每节只补入本节需要的数量、价格、日期、凭证和政策条件；正常情景之后增加一到两个异常。前一课的决定会影响后面的可用额度、提货安排、库存、头寸、销售与资金。

表格预填基础资料，学员主要做核对、判断、补字段和解释差异。用同一业务号和批次号维护一套记录，减少重复录入。

原2000吨采购、3000吨双工厂采购、400多万元销售和5000吨移仓材料继续保留为素材。原件尚未取得的量价、公司关系、真实利润不补造，也不将不同案例的数量合并。真实材料只在足以支持判断时替换模拟数据。

## 5. 必须保留的业务口径

- **供应商授信两方向分别分析。**我方预付货款、未抵扣业务保证金、应退未退金额所形成的风险，与供应商给我方账期、我方应付款义务分开记录。
- **信用计算先给公司政策。**额度预占、实际占用、释放、关联集中以及保证金、担保或票据是否可以抵扣，均由案例给明口径；不默认抵扣100%，也不用下游应收抵上游预付。
- **款货票合一指可追溯、可核对。**合同、批次、交付、收付款、结算与发票相互对应；阶段性数量、金额和时间差异须有原因与处理记录，不要求每一时点三者金额机械相等。
- **四项分别核对。**库存及交付、价格头寸、信用占用、经营现金分别记录。已提完不等于整单结清，额度充足不等于现金充足，期现合并盈利不等于没有保证金压力。
- **头寸从定价状态出发。**采购和销售是否固定价格、数量、月份、实际成交与已有持仓分别核对，不能机械地“出库就全平”或把卖开等同卖平。含税/不含税及套保系数由题目说明。
- **移仓逐笔核算。**旧仓平、新仓开、最终平和合同基差调整分别记录；不把已包含在逐笔损益中的月差再次加成利润。普通采购配套平仓与正式期转现区分；集合竞价不保证指定双方成交。
- 具体交易所、会计税务及合同适用规则，在对应课需要时核对当期官方资料和公司制度。课程只评定案例能力，不把课堂方案写成真实审批或成交。

## 6. 单课时间与工作量

| 环节 | 时间 | 具体做法 |
|---|---:|---|
| 核心方法与必要前置检查 | 20分钟 | 最多三个新重点，已有概念直接调用 |
| 连续案例 | 45分钟 | 正常流程后加入一两个异常 |
| 主要输出 | 30分钟 | 在预填资料上完成一份判断/核算/对账结果 |
| 费曼与纠错 | 20分钟 | 三个应用问题，当场定位错误 |
| 记录下一步 | 5分钟 | 已会、待补、下一动作 |
| 文华或纸面头寸核对 | 30分钟 | 核实际/模拟记录，与当课业务相关联 |

核心学习共120分钟，加风险核对30分钟。无真实任务时用纸面或已有模拟记录，不为作业新增仓位，不虚构真实业务。不额外布置必须完成的课后资料包；个人反复练习按实际需要选择。
