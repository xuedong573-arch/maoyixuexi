> 约2.5小时：理论、业务案例、Excel、文华财经、费曼各30分钟。

今天将前三天串起来：定价状态决定风险方向，风险数量决定期货手数，实际开平仓与销售点价共同决定结果。学会分别计算现货、期货、合并毛价差与列示成本后的贡献，再解释现金流压力。
所有数值均为教学假设，不是实时行情或真实公司业务。主案例作交易价差练习，暂不展开增值税抵扣、销项及所得税；“贡献结果”仅扣题设列示成本，不等于财务净利润。正式预算另按财务统一口径核算。

## 一、理论｜把四层结果分开（30分钟）

### 1. 四层计算

| 层次 | 计算方法 | 回答的问题 |
|---|---|---|
| 现货买卖价差 | 销售价−采购价 | 货物买卖本身差多少 |
| 期货累计损益 | 空头开仓成交价−平仓成交价，再乘对应吨数 | 套保头寸累计赚亏多少 |
| 期现合并毛价差 | 现货买卖价差+等量匹配的期货单吨损益 | 两端价格与套保合起来差多少 |
| 列示成本后的贡献 | 合并毛价差−本题所有列示业务成本 | 还剩多少覆盖其他费用与利润 |

表中期货公式只对应卖出套保。多头计算反过来。数量不同、分批成交或换月时，先分别算各笔总金额，再合并；不要随意加不同分母的“单吨结果”。

期货保证金是资金占用，不是缴进去就全部成为费用。手续费、资金占用成本和实际交易亏损则分别核算，不重复扣同一项目。
期货累计损益可能已经逐日结算，不能在当前权益上再次加一次累计盈亏。

### 2. 基差变化怎样出现在利润里

采购时S0=F0+B0；销售时S1=F1+B1。
若同一具体合约、同量、对应定价时点卖开F0、买平F1：

合并单吨毛价差 = (S1−S0)+(F0−F1) = B1−B0。

因此B0=−10、B1=+10，合并毛价差为20元/吨。
这需要：
- 两端价格口径可比（品质、地点、交货、税费等差异已核查）；
- 采购定价与卖开、销售定价与买平对应；
- 同一具体合约且数量匹配；
- F0/F1确实对应成交价，或成交偏差另计；
- 买卖合同能够履行；
- 成本另外完整计入。

如果销售基差+10还只是报价或意向，并未形成有效条款，就只能预算，不能宣称已经赚到20。即便基差条款有效锁定，也还有履约、执行和费用等风险。
CME卖出套保教学说明：现货上涨时空头可能亏损，下降时空头可能盈利；最终效果还受基差变化影响。不能只按期货账户盈亏评价套保。

## 二、业务案例｜从20元毛价差到8元贡献（30分钟）

### 1. 主案例：采购与开仓

采购1000吨，固定价2990元/吨。
同一参考合约AO2701当时3000，采购基差2990−3000=−10。
销售尚未最终定价，按100%数量套保：1000÷20=50手，卖开50手实际成交3000。
采购与销售价视为同品质、同地货物价格；以下装卸/短倒等费用另外列示，避免与价格内已含费用重复计算。交易发生在普通交易月份。

### 2. 销售与平仓

之后客户同量按AO2701+10最终点价。对应AO2701为2800，销售价2810；同时买平50手，实际成交2800。

| 项目 | 单吨 | 1000吨总金额 |
|---|---:|---:|
| 现货买卖价差 | 2810−2990=−180 | −180000 |
| 期货空头累计损益 | 3000−2800=+200 | +200000 |
| 合并毛价差 | −180+200=20 | 20000 |

不能说“期货赚20万元，因此业务赚20万元”，也不能说“现货亏18万元，因此整笔亏18万元”。先合并，再扣费用。

题设列示成本（均为假设预算值，不是实际市场收费）：
- 装卸/短倒6元/吨；
- 仓储1元/吨；
- 资金成本4元/吨；
- 开平仓合计手续费折合1元/吨。
合计12元/吨，1000吨为12000元。

本题贡献结果 = 20−12 = 8元/吨；
总贡献结果 = 8×1000 = 8000元。
这是简化口径下列示成本后的贡献，不等于财务净利润。

资金成本4元/吨是本题直接给定，并不默认占用一个月。实际资金成本按垫资额、实际占用天数和资金利率计算；采购付款、提货、销售点价、销售回款的日期要分别记录。承兑还需核查兑现/贴现安排。费用若已包含在价格或成本中，不再重复加。

### 3. 期货涨了，也能有相同的组合结果

如果最终AO2701为3200、销售基差仍+10，则售价3210：
- 现货单吨价差3210−2990=+220；
- 空头单吨累计损益3000−3200=−200；
- 合并仍20元/吨；
- 列示成本仍12元时，贡献仍8元/吨。

但空头累计亏损200000元会影响期货资金，现货增值不一定同步收到现金。
是否需补款、需补多少，取决于账户已有权益、可用资金、保证金等，不能把累计亏损直接当成追加金额。

### 4. 基差没有兑现，预算会变化

起始基差−10不变，假设费用总计仍12：

| 实际销售基差 | 合并单吨毛价差 | 列示成本后的单吨贡献 |
|---:|---:|---:|
| +10 | 20 | 8 |
| 0 | 10 | −2 |
| −20 | −10 | −22 |

这不是说有效锁定的+10会随意变化；假设的是+10尚未锁定，最终实际成交基差不同。
费用也可能变化：实际销售基差仍+10，但资金成本由4增到10，其他成本不变，则总成本18，贡献降为2元/吨。这一变化同样不能从“期货价格抵消”里获得保护。

### 5. 实际成交偏差会侵蚀20元

采购仍2990、参考期货价3000；销售仍2810、点价参考期货价2800。
但实际卖开成交2998，实际买平成交2802：

- 现货价差：−180元/吨；
- 期货累计损益：2998−2802=196元/吨；
- 合并毛价差：16元/吨；
- 列示成本12元/吨后：4元/吨，总贡献4000元。

相对理想结果，两端各差2元，共少4元/吨，即4000元。
成交偏差和手续费是两个项目；本例期货差额已经用实际成交价体现偏差，不再把同一偏差扣第二次。

### 6. 分批销售的扩展复盘

同样采购1000吨2990、最初卖开50手3000：
- 第一次600吨售价2810，买平30手2800；
- 第二次400吨售价3110，买平20手3100；
- 两次均参考同一AO2701、基差+10，列示成本每吨12。

第一批：现货−108000，期货+120000，合并毛价差12000，贡献4800。
第二批：现货+48000，期货−40000，合并毛价差8000，贡献3200。
合计贡献8000。每次最终定价后核查相应空头减少，第一批后还剩20手，第二批后为0。
最终总价固定与实物发出、收款是不同节点；未点价或合同取消时重新评估风险。

## 三、Excel｜一张表计算整笔业务（30分钟）

每行记录一批已完成定价及对应期货开平仓的货，主案例先做1000吨一行。

| 列 | 字段 | 第2行输入/公式 |
|---|---|---|
| A | 数量吨 | 1000 |
| B | 采购价 | 2990 |
| C | 销售价 | 2810 |
| D | 空头开仓实际成交价 | 3000 |
| E | 空头平仓实际成交价 | 2800 |
| F | 对应已平空头手数 | 50 |
| G | 现货价差总额 | =(C2-B2)*A2 |
| H | 期货累计损益总额 | =(D2-E2)*F2*20 |
| I | 列示单吨成本 | 12 |
| J | 列示总成本 | =I2*A2 |
| K | 合并毛价差总额 | =G2+H2 |
| L | 列示成本后贡献总额 | =K2-J2 |
| M | 贡献折合每吨 | =L2/A2 |
| N | 数量匹配检查 | =A2-F2*20 |

主案例应得G=-180000、H=200000、K=20000、L=8000、M=8、N=0。
N不是完整风险敞口表，只检查这一批现货量与其已平期货量的数量差；未平仓、其他业务和合同义务还要放在Day20动态台账里分析。
F登记实际成交手数，不用计划手数替代。多笔开平仓先逐笔核算，或用正确加权价格，并保留原始成交记录。

复制情景：
1. 上涨：C=3210、E=3200；
2. 基差走弱：C=2800、E=2800；
3. 成交偏差：D=2998、E=2802，C仍2810；
4. 资金成本上升：I由12改18，其他维持主案例。

最后选做分批案例，两行600吨与400吨，核对现货、期货、费用、贡献的列合计。不要把每行“每吨贡献”直接相加，整体每吨贡献用总贡献除总数量。

## 四、文华财经｜复盘一笔完整模拟套保（30分钟）

优先使用之前已有的模拟开平仓成交记录，不必为凑数据重复交易；没有可用记录时在模拟账户练1手，或提交准确操作计划。
纸面假设20吨现货固定采购、销售未定价；选普通交易月份且可用的AO完整合约。模拟卖开1手，再在纸面假设对应20吨最终售价已确定时买平1手。
交易单位20吨/手；1元/吨价格变化对应1手20元的损益变化，未计费用。

记录：
- 日期时间、完整合约；
- 卖开实际成交价和数量；
- 买平实际成交价和数量；
- 期货累计毛损益=(卖开价−买平价)×20；
- 实际手续费与扣费后交易结果；
- 前后持仓、权益、可用资金、占用保证金。

买一是当前最佳买入报价，卖一是当前最佳卖出报价。卖开时参考买一，买平时参考卖一；显示报价不是保证成交价，以实际成交记录为准。
将对应纸面采购价/销售价标记为假设，组合结果也只作为纸面教学；不能称为实际现货利润。若直接取对应成交价−10与+10设定纸面价格，20元只是练习假设，不是验证市场确实可获得该基差。
只有委托没有成交，就没有这笔新仓位/已平仓事实；准确记录未成交状态。
期货累计盈亏与账户权益变化可能因逐日结算、其他仓位、手续费和出入金不同。全账户权益不能替代单笔业务利润。
