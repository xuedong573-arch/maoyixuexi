今天从单笔套保走向公司头寸总表：库存到底有多少？哪些采购与销售还没定价？期货多空合起来，组合怕上涨还是下跌？
所有业务、数量、价格为教学假设，不是公司真实头寸或实时建议。采用同品种、同参考合约、相匹配风险期间、每吨对期货价格1:1敏感的简化模型；不同地区/品质的基差、时间和资金风险另管。该表不是财务会计报表。

## 一、理论：库存、业务价格敞口、期货头寸分别登记（30分钟）

### 1. 三种数量

| 数量 | 问题 | 必要证据 |
|---|---|---|
| 实物库存 | 货权归谁，实际有多少，放在哪里？ | 入出库、库存与货权确认 |
| 业务价格敞口 | 哪些数量的买卖结果还受价格变化影响？ | 采购/销售最终定价状态、合同及点价确认 |
| 期货持仓 | 实际持有哪些月份、多少多头/空头？ | 成交与持仓记录 |

固定价采购1000吨，400吨有效固定最终售价，600吨未定售价。货仍在仓库时，实物库存1000，简化业务下跌敞口600。
反过来，300吨采购未点价、最终销售价已固定，即使未收到货，也有采购上涨风险。
库存按货权口径登记；已出售但代管等情况另列，不把所有仓库内货都当自己的库存。合同量、实提量、已点价量不是同一个字段。

### 2. 正负号的含义

本课统一：
- 正敞口：价格上涨对业务有利，主要怕下跌。
- 负敞口：价格上涨对业务不利，主要怕上涨。
- 零：在当前简化共同价格因子下没有净方向敞口，不等于所有风险为零。

| 匹配业务状态 | 简化业务敞口 | 原因 |
|---|---:|---|
| 固定成本持货，最终售价未定 | +吨数 | 未来售价下降会压缩结果 |
| 采购未定价，最终售价固定 | −吨数 | 未来采购上涨会压缩结果 |
| 采购与销售均最终固定 | 0 | 同量、正常履约时主要价差已固定 |
| 两端均未定价 | 先逐端分析 | 参考月份、数量和点价时间可能不同 |

两端未定价如果同量、同一价格因子，同时对其1:1敏感，当前两端敏感度可能抵消；先后点价会改变状态，不能据此认为整个业务期间都无需管理。
一个合同里不同数量状态不同，要拆行。例如400吨已销售定价、600吨未定价分两行，不整单贴一个标签。

### 3. 净敞口公式

先逐笔按定价状态算有符号业务敞口，不把库存与采购合同重复计入。

业务净敞口Q = 各笔业务有符号敞口之和。
期货净吨数H =（实际多头手数−实际空头手数）×20。
组合净敞口R = Q+H。

简化同幅价格变化情景：
组合结果变化约为R×价格变化（元/吨），未计基差、费用等。这是敏感度情景，不是已实现利润。
AO交易单位20吨/手；其他品种不能直接使用20。

注意与Day20公式符号衔接：
只有空头时，H=−空头手数×20，于是R=Q−空头手数×20，与Day20一致。
公式只在同一可比风险桶内直接相加。至少按品种、参考月份、风险结束/点价窗口分组；地区、品质和物流差异也要分析。

## 二、公司组合案例（30分钟）

### 案例A：库存1000吨，业务净敞口却是+300吨

假设所有价格风险均参考AO2701、点价/管理期间相匹配，合同可履约，价格每吨同幅变化：
- 业务A：固定价采购且已持有1000吨；其中400吨已有效固定最终售价，600吨未定价。
- 业务B：另有300吨采购未点价，最终销售价已固定；尚未收到货。
- 期货：同一AO2701实际多头5手、空头20手（历史分业务持仓的教学快照，不要求新增双向仓位）。

| 项目 | 有符号吨数 |
|---|---:|
| A中已固定两端价格的400吨 | 0 |
| A中未固定售价的600吨 | +600 |
| B中采购未定、售价固定的300吨 | −300 |
| 业务净敞口Q | +300 |
| 期货多头5手 | +100 |
| 期货空头20手 | −400 |
| 期货净吨数H | −300 |
| 组合净敞口R | 0 |

不能把库存1000再加业务A采购1000，这是重复计数。
实际库存本例1000；B未收货，但存在−300采购价格敞口。也不能对所有仓库库存一律开50手空头。

净空头相当15手，不代表持仓页面只有15手空头：实际还有5多、20空。历史头寸与业务归属必须保留。总手数25、净手数−15回答不同问题；保证金按实际账户和合约规则核查，不直接由净吨数推断占用归零。

### 案例B：价格同步上涨100，组合怎样变化？

仅看相关风险部分：
- A未定价600吨，价值/可实现售价增加60000；
- B未点价300吨，采购成本增加30000，对业务结果影响−30000；
- 期货多头100吨赚10000；
- 期货空头400吨亏40000；
- 合计0。

同步下降100时，各项方向反过来，合计也为0。
这不是说利润等于0，而是说简化共同价格变化没有改变原有组合结果。现货、期貨现金流不同时发生；未来报价变化或库存估值不是现在已收利润。

### 案例C：客户又把200吨销售最终定价

业务A原有600吨未定价，其中200吨有效固定最终售价：
- A敞口从+600变+400；
- B仍−300；
- 新Q=+100；
- 期货仍5多、20空，H=−300；
- 新R=−200。

组合现在主要怕上涨。假设同步上涨100，简化结果减少20000。
按目标净方向敞口0的教学设定，需要把期货净吨数从−300调整到−100，即增加200吨的净多方向。

如果选择买平10手原空头：
- 空头20→10，多头仍5；
- H=(5−10)×20=−100；
- R=+100−100=0。

动作是买平原空头，不是把已固定销售部分继续当未定价库存，也不必为了数量变化额外买开10手。真实调整仍按公司授权、业务归属和账户限制办理。

若买平10手委托只成交6手：
- 空头实际14手；
- H=(5−14)×20=−180；
- R=100−180=−80；
- 不能记已完成目标调整，还需处理剩余4手委托/风险。

### 案例D：业务B采购完成点价

回到案例A初始状态，独立设想B的300吨采购全部有效定价、售价仍固定：
- B从−300变0；
- A仍+600；
- Q=+600；
- 原H=−300；
- R=+300，仍有300吨下跌敞口。

目标R=0时需要增加相当300吨的净空头方向。例如教学纸面在匹配条件下卖开15手，使H从−300变−600。
这与案例C是两条独立情景，不在同一行连续相加。
如果库存或销售义务、合同履约发生变化，还须重新逐笔评估，不能只按点价量机械处理。

### 案例E：总吨数净零，月份仍可能错配

另一独立组合：
| 风险桶 | 简化敞口 |
|---|---:|
| AO2701 | +600吨 |
| AO2703 | −600吨 |
| 不分月份的总和 | 0 |

若AO2701上涨100、AO2703不变，简化结果+60000。
若AO2701不变、AO2703上涨100，简化结果−60000。
所以不同月份不能仅靠总和0宣称风险消失，必须保留每月敞口及月差风险。不同点价期限、地区、品质也有相同的匹配问题。

### 案例F：零净敞口仍有其他风险

- 基差：库存现货下跌50，参考期货不变，600吨风险部分可能损失30000；原来的期货匹配不保证弥补。
- 信用：客户不付款、订单取消，价格固定的前提可能不再成立。
- 质量/数量：不合格、扣价、损耗、实提差异影响业务。
- 现金流：期货空头亏损需资金，库存涨价或客户款项未同步变现。
- 月份/时间：合同点价延期、持仓到期、换月和执行不同步。
- 执行：委托未成交、只成交一部分、成交价偏差。

先做净方向分析，再分别登记这些风险。0不是风险全部解除的证明。

## 三、Excel：业务表、期货表与分组汇总（30分钟）

### 表1：逐笔业务定价状态
| 列 | 字段 | 示例 |
|---|---|---|
| A | 业务编号/批次 | A-未定销售 |
| B | 该状态对应吨数 | 600 |
| C | 采购最终价状态 | 已固定 |
| D | 销售最终价状态 | 未固定 |
| E | 经核查方向系数 | +1 |
| F | 有符号业务敞口 | =B2*E2 |
| G | 完整参考合约 | AO2701 |
| H | 风险结束/点价窗口 | 教学共同窗口 |
| I | 库存与交付状态 | 在库、货权已确认 |
| J | 定价确认/合同证据 | 记录依据 |

案例A三行：400吨系数0，600吨系数+1，B业务300吨系数−1，敞口合计+300。
方向系数基于两端定价与履约状态审核，不能仅按“采购/销售”字样自动赋值。两个未定价的复杂业务须逐端及分窗口分析。

### 表2：实际期货持仓
A合约，B实际多头手数，C实际空头手数，D净吨数，E业务归属：
D2=(B2-C2)*20。
例AO2701多5空20，D=-300。
只填成交后的实际持仓；计划、未成交、冻结/可用数量分别记录。

### 表3：按合约及窗口汇总
| 风险桶 | 业务敞口Q | 期货净吨数H | 组合R=Q+H | 上涨100情景 | 下跌100情景 |
|---|---:|---:|---:|---:|---:|
| AO2701共同窗口 | 300 | −300 | 0 | 0 | 0 |

同组单元格公式：组合=业务+期货，上涨情景=组合*100，下跌情景=组合*(-100)。
Excel用SUMIFS按合约及窗口汇总，先确保同窗口字段确实可比；不直接跨月份求和代替风险判断。
再做案例C变更后及只成交6手两行快照，核对0→−200→0或部分成交−80。
实物库存另用入出库台账核对，预付、应收、发票另列；金额和吨数不要混加。
