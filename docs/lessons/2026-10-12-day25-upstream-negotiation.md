## 一、理论：同一个“价格”有三种谈法（30分钟）

| 模式 | 价格公式 | 采购时重点谈什么 | 尚未确定的部分 |
|---|---|---|---|
| 一口价 | 直接约定X元/吨 | 品质、地点、时间、含税/运杂口径、数量和付款对应的X | 有效确认后相应货价固定，履约/费用风险另管 |
| 网价月均价 | 指定来源、地区/品种口径、周期平均价+升贴水 | 来源/字段、平均方法、统计日期、升贴水、暂结/最终结算 | 月均价未形成时最终货价未固定 |
| 期货加基差 | 指定AO合约的约定点价价+B | 完整合约、B、点价权、窗口、执行价与确认、未点价处置 | 未点价部分的期货价未固定 |

示例：
- “山东某具体厂、500吨、厂自提、2688元/吨”是一个一口价条件包，还要补明确含税、装卸和交期等。
- “资讯源X、指定山东某牌号每日评估中值、2026年11月有效发布日的算术平均价+5”是月均价示例。X为占位，不是真实资讯源；还需约定节假日无报价、修订/停发和替代来源，不能只写“按山东月均价”。
- “AO2701按合同确认的点价价−10”是基差价。主连/加权不是这里的具体参考合约。

CME基差教学说明S−F会受到地点、运输、品质、供需等因素影响。不能只比较升贴水数字而忽略交货条件。
固定价没有消除信用、质量或运费变化；月均价不等于每天不会涨；锁基差不等于锁总价。

### 四个“时间”分别登记

1. 提货周期：何日起可提、每批多少、最晚何时提完；
2. 点价窗口：何日起可点、截止日与时刻、分批点价规则；
3. 参考期货月份：AO2701等完整代码；
4. 付款/开票/结算期限：预付、批款、最终补退与开票日期。

不能用“一个月周期”代替这四项。录音里的“期货周期”若实际指提货周期，要确认对方说的究竟是哪一项。

## 二、谈判案例：预算上限不等于应该付到上限（30分钟）

### 1. 延续Day24，但上游报价是新假设

昨天原厂家A最低5000吨，不能擅自改成500吨。本课另行假设A已经愿意单独报500吨的新条件，不意味着原报价自动可拆。

下游：有效固定500吨最终售价2760元/吨到厂。
替代上游B：2728元/吨到厂，500吨，条件可核查。
厂家A新报：500吨，一口价2688元/吨厂自提；运杂费42元/吨。
其他成本3元/吨，资金年利率6%，资金占用35天。
本例为统一比较，假设货价及运杂费均在第0天垫付、同样占用35天；实际按各笔收付日期计算。
教学最低贡献目标10元/吨，未计其他税费；质量交期和付款等可比条件先核查。

A到厂价2688+42=2730。
资金成本2730×6%×35/365=15.706849元/吨。
贡献2760−2730−3−15.706849=11.293151元/吨，500吨约5646.58元。

A满足最低10元目标，但B到厂2728，同模型贡献13.304658元/吨，比A高约2.01元/吨。
因此不能因A出厂价低，就认定A更划算；也不能因为超过最低目标就不看替代方案。

### 2. 三个价格的用途不同

- 争取价：你的谈判开价，例如2684元/吨厂自提，作为有依据的起点。
- 同等替代方案对应价：B到厂2728−运杂42=2686元/吨厂自提。同条件A不高于2686，价格层面才不比B贵。
- 预算上限：满足最低贡献10的最高价，不是默认应支付价格。

令A厂价x、到厂价x+42：
2760−(x+42)−3−(x+42)×6%×35/365≥10。
到厂最高价=(2760−3−10)/(1+6%×35/365)=2731.285753。
厂价最高x=2689.285753。
若按0.01元档报价，为保证不越上限向下取2689.28，不四舍五入到2689.29。
上限依赖运费、天数、利率和成本假设，变化后重新计算。

2688没有越预算上限，但在其他条件相同、B真实可获得时，仍比B贵。若A有可量化交期或质量优势，要单独说明价值与证据，不能凭印象加分。
争取价不是厂家心理底价；预算上限和替代方案也不需要主动全部透露。

### 3. 用条件换条件，且只承诺能做到的

| 你能真实提供的条件 | 可以向上游争取 |
|---|---|
| 确定500吨，并明确提货计划 | 匹配500吨的价格、起订量和放货安排 |
| 提前报车、集中装运 | 装车效率、合理减少等候或装卸费用 |
| 有保障的付款安排 | 相应价格或付款宽限，但先核查资金与信用 |
| 有证据的后续需求 | 后续批次另询价/有约束的选择权，不无条件承诺未锁销量 |
| 清晰质量要求和验收安排 | 规格、检验资料、异议与结算可执行性 |

不能为了便宜承诺虚假的后续25000吨需求，也不能把“后续货由我定价”当成完整条款；需明确数量义务、来源/公式、上下限、定价权和时间。
对方可以拒绝小量、短提货期或更长付款期。你的结论可以是换上游、分批另询价、保持现方案，不能假设一句谈判话术必然成功。

教学话术：
“张经理，我这批考虑500吨。请按具体工厂、批次和装车条件确认报价；运杂费测算42元/吨，我希望厂自提价争取2684。若能在2686以内并匹配提货和开票安排，我这边再按完整条件确认。当前仅讨论本批，不承诺额外数量。”
这是练习表达，尚不是采购订单；报价意向与有效合同/点价确认分开。

### 4. 贵2元，给10天付款宽限，可能更划算

独立比较两个到厂方案：
- 方案1：2728，第0天付款，第5天客户验收，第35天回款，垫资35天；
- 方案2：2730，供应商允许第10天付款，交付/验收与下游第35天回款时间不变，垫资25天；
- 售价2760，其他成本3，利率6%，无另收费用、条款和信用均可接受的假设。

方案1贡献13.304658元/吨。
方案2资金成本2730×6%×25/365=11.219178；贡献2760−2730−3−11.219178=15.780822。
方案2贵2元，但少垫资10天，贡献多约2.48元/吨。

付款宽限不是免费或必然可谈成，核查对方价格/信用/担保等交换条件。批款批货也不自动减少10天；必须按实际付款与回款日重算。

### 5. 同一家报月均价或基差时，怎么回应？

月均价示例：指定网价月均+5厂自提，运杂42。
假设预测月均2680，则到厂估算2680+5+42=2727。它不是已锁成本。
若实际月均2750，到厂变2797，已固定售价2760可能不足以覆盖采购和费用。
问清统计日期、来源、平均方法、升贴水、暂付款与最终补退；不同定价与结算时间还要重算资金。网价月均与某一笔AO成交不是同一价格因子，不能用任意AO点价就认定全部风险已锁。

基差示例：AO2701−10厂自提，运杂42。
若有效点价2700，到厂2732；点2660，到厂2692；点2800，到厂2832。
未点价时不能把2692的希望价写成采购成本。
本模型到厂预算上限2731.285753，意味着F−10+42≤2731.285753，所以F≤2699.285753。若单笔参考价按1元档位，预算上限对应2699。
若要在同等条件下不高于B到厂2728，F应不高于2696。预算边界与替代方案边界仍不同。
上游采购未点、下游售价固定，主要怕上涨，参考同合约的买入套保是此前教学方向；若采购已点但销售未定，则主要怕下跌，对应卖出套保。合约、数量、期限和资金一并核查，不自动下单。

## 三、把口头条件写成可执行条件包

至少确认以下字段：
| 字段 | 要写清楚 |
|---|---|
| 主体与货权 | 合同、收款、开票主体及授权；货物批次、存放与提货权确认 |
| 货物规格 | 品牌/工厂、牌号、具体标准和版本、客户关键指标、包装 |
| 数量与计量 | 本批吨数、最低量、每批量、计量依据与溢短结算 |
| 价格口径 | 一口/月均/基差；含税与运杂；来源/合约；报价有效期 |
| 提货 | 起止日期、每批计划、报车/装车、运杂与等候责任 |
| 点价 | 有权方、完整合约、起止日/时刻、执行价、确认记录、分批及未点价处理 |
| 付款 | 先款/批款/宽限的具体节点，账户、暂付与补退方式 |
| 验收与异常 | 取样、检验、异议期限、复检及不合格处置等协商机制 |
| 开票与结算 | 票据种类/品目/税费口径、时间、实际数量双边结算与凭证 |

“符合国标”“一个月提完”“以后开发票”都要进一步具体化。
先款后货不是一概不合理；预付款是你对上游的信用风险暴露，须按公司制度核查主体、货权、资金与保障。不要求所有厂家都接受先货后款，也不因厂家规模大就跳过核验。
开票不是只问“额度够不够”；开票主体、内容、时间和合同约定须与财务核对，不能仅据口头额度判断。

基差条款学习示例（不是完整合同）：
“本批500吨，参考AO2701，固定基差−10元/吨厂自提；买方按约定渠道分批提出点价，价格按双方确认的执行机制确定；点价窗口截至2026年11月10日14:30（北京时间，执行时段与交易日历核查）；未点数量按另行明确的合同机制处理。提货期限、付款节点和计量/开票另列。”
未点价默认机制要写出具体规则，不能只留下“另行协商”作为无风险保障；这里留空表示未完成条件包，不可当可直接签署成品。

## 四、Excel与文华任务（各30分钟）

### Excel：对比价格模式和付款条件

先比较固定到厂方案：
| 列 | 字段 | 第2行示例/公式 |
|---|---|---|
| A | 方案 | A500吨新一口价 |
| B | 数量 | 500 |
| C | 采购报价格 | 2688 |
| D | 未含运杂 | 42 |
| E | 到厂价 | =C2+D2 |
| F | 最终销售价 | 2760 |
| G | 其他单吨成本 | 3 |
| H | 年利率 | 6% |
| I | 垫资天数 | 35 |
| J | 单吨资金成本 | =E2*H2*I2/365 |
| K | 单吨贡献 | =F2-E2-G2-J2 |
| L | 总贡献 | =K2*B2 |
| M | 证据/条件缺口 | 自己填写 |

B方案C=2728/D=0/I=35；宽限方案C=2730/D=0/I=25。
保留精度算总额，显示两位。假设月均价和未点价报价另表标“预测/未确认”，不和已固定价混成同一确定成本。
预算最高到厂价=(销售价−其他成本−最低目标)/(1+年利率×天数/365)；最高厂价再减未含运杂。
再做条件包清单，各字段填已确认/待确认与证据，合同量、点价量、实提量分列。

### 文华：下单前检查，报价不等于成交

今天为观察与纸面订单检查，不要求新增仓位。
记录拟参考的完整AO合约、最新/买一/卖一、观察时间、成交/持仓及是否有更新。
按基差−10、运杂42估算F−10+42到厂货价，明确这是纸面教学；真实点价参考价依合同执行，不能把屏幕最新价自动记成交。
填写订单前检查：业务采购/销售定价状态、风险方向、理论数量、拟合约、开平类型、资金与账户/月份限制、点价确认和期货成交分别怎样保存。
AO交易单位20吨/手，最小变动1元/吨。500吨对应25手只是在确有500吨相应风险、100%数量目标和普通月份条件下的理论数，不自动形成下单指令。
软件不可用或非更新时段如实记录，用纸面流程替代，不编造成交。
