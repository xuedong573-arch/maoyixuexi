## 一、理论：不同风险需要不同工具（30分钟）

| 风险 | 例子 | 对应管理工具 |
|---|---|---|
| 价格 | 未定售价下跌、未定采购上涨 | 两端定价、基差与合约匹配、期货/净敞口 |
| 信用 | 预付后上游不交货、下游提货后不付款 | 对手核验、授信、期限、额度、付款与保障安排 |
| 质量/数量 | 不合格、扣价、短量 | 标准、取样/检验、计量与异议结算 |
| 操作 | 错误授权、重复放货、错付账户 | 复核、有效委托、累计数量控制、版本与回执 |
| 流动性 | 期货资金需求、回款晚于付款 | 分日现金流、可用资金及缓冲 |

期货不能保证客户付款、货物合格或授权正确。业务有利润也不代表款项已经到账。

### 1. 授信是什么？

本课授信：公司在核查对手和交易后，批准在一定期限、额度、付款方式与条件内承受信用风险。额度之外还要看：
- 授信对象是否为这个合同主体、有效期是否覆盖；
- 批准现金账期还是可接受票据，承兑人要求是什么；
- 已占用、到期和逾期情况；
- 担保、保证金及其他批准条件；
- 哪些情况暂停新增，哪些例外须重新审批。

授信50万不等于“每张单都能再放50万”。通常管理的是一定口径下同时占用的风险额度，而不是累计全年销售额；具体口径依制度。
公司风险占用可能包括应收、已放未结、批准未执行承诺、未到期票据等，需统一口径且避免同一债权重复计入。
银行承兑收到和现金到账分别记录；央行办法区分承兑与贴现，贴现为到期前付息取得资金的安排。本例不把未验票据自动抵现金。

### 2. 上下游授信方向不同

向上游先款后货：你先把资金付给上游，承担交货、货权及返款等风险。
向下游先货后款：你先把货交给下游，承担回款风险。
先款后货不是自动错误，先货后款不是只凭客户规模就可接受；都要匹配合同与公司制度。

## 二、案例一：50万额度，能放100吨吗？（30分钟）

教学假设：
- 客户C有效授信50万元，30天现金账期；
- 当前已放货未回款32万元，无逾期；
- 本例其他占用、未执行预留与认可担保抵减均为0；
- 新申请提货100吨，最终价2760元/吨；
- 合同约定本批可按剩余额度和实际确认预付款安排放货；
- 本批货物和授权另需核验，不因额度计算通过自动全部放货。

剩余额度=500000−320000=180000。
新货值=100×2760=276000。
全放后的占用=320000+276000=596000，超96000。

可以讨论三种有条件方案：
1. 确认预付款至少96000元，并明确冲抵本批；本例风险占用降至500000。以财务核验到账和分配记录为准，不凭汇款截图。
2. 在数量、装运、合同和公司规则允许时先放不超剩余额度的数量：180000÷2760=65.217391吨；例如65吨货值179400，累计499400，余600元额度。真实吨数与计量精度另核；不是所有业务都按整吨或必须放65吨。
3. 按制度申请新增额度/其他保障，在有效批准前不当额度已经增加。

若有逾期或其他限制，即便金额未超限也须按制度核查。本例“暂停新增放货”对应合同已约定前提或尚未承诺的新增安排；存量合同义务与变更另按合同处理，不单方面把内部额度规则当取消合同理由。

### 回款要区分状态

| 状态 | 是否可按已确认现金使用 |
|---|---|
| 客户说已转 | 不是确认到账 |
| 汇款截图 | 提供核对线索，仍须核验 |
| 公司财务确认银行到账并分配合同 | 按确认金额和条件登记 |
| 承兑已验收 | 单列票据、承兑人、到期及可使用条件，不直接等于现金 |
| 承兑实际贴现到账 | 现金与贴现费用分别登记 |

付款方/收款账户或合同主体不一致，先核对合同、授权与资金归属。变更信息通过已有可信渠道复核，留存批准和确认，不凭临时陌生消息改账户。

## 三、案例二：提货委托与放货授权怎么衔接？

设贸易公司T向上游U买货，再卖给客户C，物流L受托提货。
录音中“把客户给你的委托做成你们自己的再给上游”，在本课解释为：保留C对T的原始授权，由T以自身名义另行签发对U的提货委托，核对原授权中司机/车辆/物流信息及权限。

### 执行链

1. C向T提交有效提货申请与委托：合同/批次、数量、物流公司、司机/车辆、提货时间、授权渠道与签发人。
2. T核查合同、定价状态、收款/额度、累计提货及剩余量、货权/批次和异常。
3. T签发本公司对U的有效委托：仅在自身可授权范围内，明确本次数量、批次、有效时间与提货主体；客户原授权和T新委托分别保留。
4. U核验T权限、库存及放货条件，书面/系统确认后，T通知C可安排提货。
5. L依工厂入厂/报车规则提货；取得出库、磅单、签收等实际记录。
6. T核对上下游实际数量与结算，核销本次授权，更新款项与发票状态。

客户委托证明谁受客户委托来提，不单独证明T已经有权让U放货。车辆到厂也不代表批准放货。
提货单、库存证明和仓单的作用不同，核查有效权利和仓库/上游确认，不能只凭文件名称判断。

### 委托单具体核查
- 合同与批次是不是正确？
- 本次吨数，是否超过合同余量、已获放货权限或额度？
- 司机、车牌、物流和受托方是否与有效授权一致？
- 委托是否仍有效，是否已经被使用/作废？
- 上游是否已确认，实际放货与授权是否相符？
- 临时换车、换人、增加数量时，原有委托怎样变更和核销？

临时变更时用有效渠道确认更新，保留版本，避免旧新两份重复放货；未核验时按约定流程暂缓本次未满足条件的放货。不得擅改他人签章或冒用授权。

## 四、案例三：1000吨签约，最终只结算999吨

独立教学例子：
- 销售合同1000吨，固定价2750元/吨；
- 客户已预付全额2750000；
- 双方已经明确取消剩余1吨，并同意最终按999吨结算，无额外违约费用或其他调整；
- 实提/验收999吨；
- 已开具并核对对应800吨的发票；
- 其他费用本例暂不计。

实际应结金额=999×2750=2747250。
多收=2750000−2747250=2750。
已开票金额=800×2750=2200000。
待开票对应量=999−800=199吨，金额199×2750=547250。

分别记录：
| 字段 | 本例 |
|---|---:|
| 原合同吨数 | 1000 |
| 实提/最终结算吨数 | 999 |
| 已确认取消吨数 | 1 |
| 已收预付款 | 2750000 |
| 最终应结货款 | 2747250 |
| 应退差额 | 2750 |
| 已开票吨数/金额 | 800 / 2200000 |
| 待开票吨数/金额 | 199 / 547250 |

待开票547250不是客户还欠547250：本例货款已预收，反而应退2750。票、款各有自己的余额。
2750是结算退款，不是业务利润；547250是未开票部分，不是未收现金。
只有“少提1吨”时不能自动退款或关闭原合同：先确认是未提、取消、磅差还是损耗及双方规则。本例已经确认取消才按999结算。
上游采购也需独立核对其实际数量和合同：下游999不自动把上游1000改成999。若余1吨归T且未定价销售，仍列库存及价格风险；若上下游均按999结清且没有剩余义务，则核实对应风险归零。
发票/资金调整按真实业务和财务流程，不把1吨差异随意抹平或虚构交付。

## 五、四张台账与关闭业务条件

| 台账 | 最低字段 |
|---|---|
| 合同/定价 | 主体、数量、价格公式、已点/未点、截止与交期 |
| 货物/授权 | 货权、批次、每次申请/批准/实提、累计余量、委托版本、磅单 |
| 款项/信用 | 应收应付、实收实付、预付与退款、票据、期限、额度占用 |
| 发票/结算 | 应开/已开/待开、上游应取得/已取得、实际数量、结算单与差异 |

同一合同号贯穿几张表；上下游分行，资金方向分开。实提、开票、收款不会因为另一项完成就自动同步完成。
Excel显示差异是一种提醒，不是差异原因的自动判定。要能追到合同、点价确认、放货授权、实际出入库、结算和财务凭证。

业务关闭核查：
- 最终数量与余量处理双方已确认；
- 采购/销售定价、应收应付与补退已清楚；
- 质量数量异议按约定处理，未结事项登记；
- 发票取得/开具、电子或纸质记录与其他证据已核对；
- 对应期货成交、持仓和损益已归属，残余库存/敞口不漏记；
- 预算与实际差异可解释。
只有“发票开了”或“原件收了”不意味着整个业务已经结束。

## 六、Excel与文华任务（各30分钟）

### Excel：额度与票款货两张表
额度表输入：
B2授信500000；B3已占用320000；B4本次吨100；B5价2760；B6财务确认且认可抵本批的预付款0。
剩额度=B2−B3；
本次货值=B4*B5；
本次新增风险占用=MAX(B4*B5−B6,0)；
执行后占用=B3+MAX(B4*B5−B6,0)。
本公式假设全部预付用于本批、未超货值。超收款另列，不以MAX抹掉退款义务；旧应收回款冲抵时按实际分配更新B3，不能重复减B3和新增占用。
分别试65吨与100吨/预付96000，记录累计占用499400和500000。仍另列授信有效/期限/逾期/票据规则/授权等状态，数值通过不自动批准放货。

对账表：
原合同1000、最终结算999、单价2750、已收2750000、已开量800。
应结金额=最终结算量*单价；
结算差额=已收−应结，正数本例应退，负数本例应收；
待开票量=最终结算量−已开量；
待开票金额=待开票量*单价。
负待开量标为超开/待核验，不强行改0。金额与吨数不能混加；状态还需要真实结算确认。

### 文华：条件单、止损只是执行工具认识

观察软件“条件单/添加条件单/损盈”等可用界面，记录实际名称；不要求新增仓位或触发交易。没有该功能/不可用如实说明，不假设某版本界面或云/本地行为。
明确三种价格：
- 触发价：满足后启动动作的条件；
- 委托价/方式：触发后实际提交的订单；
- 成交价：市场最终撮合的实际价格。

期货公司官方帮助说明：部分本地条件单受关机/休眠影响；触发、可用持仓和成交价受实际软件及撮合条件影响，不能保证按设定触发价成交。是否云端、断线执行、有效期与触发依据须按实际版本/账户帮助核查，不把别的软件规则套到文华。

纸面例子：AO空头1手卖开2700，设触发价2730，假设触发后按允许的订单方式最终买平成交2733：
累计毛损益=(2700−2733)*20=−660，未计手续费。
若用2730当成交会算−600，少算60。此例假设提交方式允许2733成交，不把买入限价2730说成可以成交2733。
若未成交，头寸并未解除；只有成交才更新持仓。

套保账户的空头亏损可能对应现货增值，不能仅因期货单腿亏损机械平掉保护仓。若条件单触发平仓但20吨固定成本现货仍未定售价，期货空头已无，组合重新留下+20吨下跌敞口。同步更新业务风险和处置安排，不把期货止损等同业务风险解除。
止损/条件单不能核验收款、客户信用或提货授权，不能替代放货控制。

## 七、费曼与执行决策练习（30分钟）

请按编号回答：
1. 期货套保、授信和提货授权分别主要处理什么风险？为什么客户有授信不等于每批都能放货？

5. 1000吨2750，已预收全额，最终双方确认999吨结算，已开800吨：应退多少、待开多少吨及金额？为什么待开票金额不等于客户欠款？

8. 写100—200字放货决策：本批申请100吨、额度50万已占32万，客户只有汇款截图且临时换车；按本课合同前提说明当前能否直接放、需补哪些确认、如何记录授权变更及可讨论的数量/补款方案。附额度或对账Excel/纸面结果与文华观察。
