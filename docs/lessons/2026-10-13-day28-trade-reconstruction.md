# 正式 Day 28｜把一笔氧化铝业务从采购复盘到结清（详解版）

> 重学日期：2026-10-13（北京时间）。沿用原案例，增加逐步解释；不是新增一天。
> 状态：进行中，待作答、台账与文华观察验收；已完成仍为2/30，以课程状态卡为准。
> 建议用时：理论30分钟、案例30分钟、Excel/纸面30分钟、文华模拟观察30分钟、费曼30分钟。

今天的目标是：**能把“货去了哪里、价格怎么定、期货怎么配、钱票是否结清、整笔赚了多少”说清楚，并让每个答案都有凭证。**

以下是教学模拟，不是录音中真实完成单或今日行情。所有价格单位为元/吨，数量单位为吨；现货为模拟合同结算价，期货为假设实际成交价。统一品级、交付地点和同一AO具体合约，本例不换月。价差与费用计算不展开增值税及正式会计处理，最终“简化贡献”不能当财务净利润。

**一、为什么“买了1000吨、卖了1000吨”还不算复盘？**

因为同一笔业务中，六件事可能在不同时间完成：

| 线索 | 要回答的问题 | 主要依据 |
|---|---|---|
| 合同与定价 | 跟谁签、多少吨、固定价还是基差、哪些已点价？ | 上下游合同、补充协议、点价确认 |
| 货物与货权 | 实际收到和放出多少、货归谁、谁有权提？ | 入库、货权证明、有效授权、磅单、签收 |
| 期货 | 哪个合约、开平几手、实际成交多少、还持几手？ | 委托、成交回报、持仓及结算单 |
| 资金 | 应收应付多少、实际到账多少、还有多少未收？ | 经核验的银行记录、付款分配、收付台账 |
| 发票 | 应开已开多少、对应哪批、上游票是否取得？ | 发票明细、批次对应、最终结算单 |
| 损益与遗留事项 | 现货、期货、费用各多少，剩货与未了事项是什么？ | 预算实际表、费用凭证、异常处理记录 |

例如客户已经付款，发票可能还没开完；期货已经平仓，仓库可能还剩货。
“已签约、已点价、已成交、已提货、已到账、已开票”要分别登记，不能用一个“完成”覆盖全部状态。

**二、先认识这笔业务中的四个人与五个时点**

U是上游厂家；T是你所在的贸易公司；C是原下游客户；D是后来买尾货的新客户。

D0、D10等表示相对业务日，不是课程编号，也不是实际交易日历。为便于学习，本例把相应批次的点价、期货平仓和提货安排在同一节点；真实业务中三者时间可能不同。

| 时点 | 现货与合同事实 | 期货事实 |
|---|---|---|
| D0 | T以2990向U采购1000吨，已付款、验收并取得可支配货权；与C签1000吨销售合同，按同一AO合约点价＋10 | 卖出开仓50手，假设实际成交3000 |
| D10 | C点价600吨，参考期货价2800，售价2810；有效放货并实提600吨 | 买入平仓30手，实际成交2800 |
| D30 | C点价并实提399吨，参考期货价3100，售价3110；双方确认取消C合同剩余1吨 | 买入平仓剩余20手，实际成交3100 |
| D40 | C按999吨结清货款；已开800吨发票，另199吨待开 | 持仓0手，但T仍有1吨未售库存 |
| D45 | T与D另签合同，将剩余1吨以3120卖出、交付并收款；本例余下发票、费用和差异核对完成 | 无新增期货交易，库存与持仓最终均为0 |

放货衔接沿用Day27：C的提货申请 → T核查付款/授信与授权 → T对U签发自身有效提货委托 → U确认 → 实提签收。点价或期货平仓不能替代放货审批。

**三、D0：为什么买了货以后要卖出开仓？**

你已经以2990买进1000吨，采购成本固定；C只是签了“期货价＋10”，尚未点价，所以最终销售总价仍会变化。

若点价时参考期货为2800，销售价为2810；若为3100，销售价为3110。
因此，这1000吨仍面对售价下跌风险。为本例的固定成本、未定售价库存建立匹配空头，是为了让期货腿与现货价格风险方向相反。

AO交易单位为20吨/手，报价单位为元/吨。见文末上期所规则。

1000÷20＝50手，所以本例卖开50手，假设全部成交于3000。
“卖出开仓”是建立空头；之后“买入平仓”是了结该空头。两者不等于把仓库实物交给期货市场。

买入时的比较基差：
采购价2990－同期参考期货3000＝－10。

销售约定为期货价＋10，销售基差为＋10。
在同量、同合约、成交匹配且没有额外偏差的教学条件下，毛价差为：
＋10－（－10）＝20元/吨。

为什么期货涨跌能被抵消？设客户最终参考期货价为F，且你的买平成交也为F：

现货价差＝（F＋10）－2990；
期货空头损益＝3000－F；
合计＝（F＋10－2990）＋（3000－F）＝20。

这里依靠的是匹配关系。若客户点价2800，而你实际买平2803，第一批每吨期货少赚3元，合并毛价差变成17元；600吨就少1800元。
所以必须记录**客户点价确认价与期货实际成交价**，不能把委托价当成交价，也不能把理论20元直接抄成实际利润。

**四、D10：先完成600吨，逐步算清楚**

客户按2800＋10点价，600吨售价2810。
本例合同和放货条件已满足，600吨已实际出库验收；对应买平30手，并假设实际成交2800。

| 第一批600吨 | 算式 | 金额 |
|---|---|---:|
| 销售额 | 600×2810 | 1,686,000 |
| 对应采购货值 | 600×2990 | 1,794,000 |
| 现货价差 | 1,686,000－1,794,000 | －108,000 |
| 期货累计毛损益 | （3000－2800）×30×20 | ＋120,000 |
| 期现合并毛价差 | －108,000＋120,000 | ＋12,000 |

按每吨看，就是现货－180、期货＋200，合并＋20。
这解释了为什么“现货亏了”不一定代表整笔业务亏了：还要看与这批业务相关的期货腿和费用。

D10所有操作完成后：
库存＝1000－600＝400吨；
空头＝50－30＝20手，对应400吨。

此时“第一批已定价并交付”并不等于“客户货款已回收”。本例C到D40才结清，期间仍有回款与资金占用问题。
真实业务若先固定售价、后提货，在销售有效可履约、相应售价风险解除且数量复核后，应协调调整对应套保；不能机械等待车辆出库或客户回款。

**五、D30：399吨为什么与20手对不上？**

第二批最终售价＝3100＋10＝3110。
C实际只提399吨；双方确认取消C合同剩余1吨。这只是原客户少执行1吨，不会改变U已经交给T的1000吨。

| 第二批399吨 | 算式 | 金额 |
|---|---|---:|
| 销售额 | 399×3110 | 1,240,890 |
| 对应采购货值 | 399×2990 | 1,193,010 |
| 现货价差 | 1,240,890－1,193,010 | ＋47,880 |

同时，本例T买平20手：

（3000－3100）×20×20＝－40,000元。

但20手对应400吨，C这一批只有399吨，差1吨。
399÷20＝19.95手，不能用整手期货精确平出19.95手。

本例选择平掉20手并单列剩余1吨的价格风险；这是一项模拟处置选择，不是所有公司都必须采用的规则。不能因为客户少提1吨，就自动把其他业务的头寸混进来。

如果只是为了分析，将这次－40,000按对应吨数拆开：

| 分析归属 | 算式 | 毛损益 |
|---|---|---:|
| C第二批399吨对应的期货部分 | （3000－3100）×399 | －39,900 |
| 剩余1吨对应的期货部分 | （3000－3100）×1 | －100 |
| 合计 | — | －40,000 |

这是**管理分析上的吨数分摊**，并不是账户实际成交了19.95手与0.05手。

C第二批合并毛价差＝47,880－39,900＝7,980，即399×20。
剩余1吨在D30卖出以前，只能记库存2990元的模拟采购成本，以及已分摊的期货－100；尚无尾货销售收入，不能提前记后来D的3120。

D30操作完成后，实物库存1吨、空头0手。
若保留1手空头，则对应20吨，而孤立的1吨库存只对应1吨风险，会产生19吨的反向数量不匹配。实际处置应看全公司净敞口、相关业务和批准的误差范围，本题只观察这一笔。

**六、D45：最后1吨卖出，整笔贡献怎么算？**

T与D另签销售合同，1吨以3120出售并交付收款。

尾货现货价差＝3120－2990＝＋130；
将之前已分摊的期货－100放在同一分析口径内：
尾货合并毛价差＝130－100＝＋30。

这不是后来又发生一笔期货亏损；－100已经包含在D30的－40,000里，不能重复扣。

现在可以用两种方法相互验证。

方法A，先汇总全部现货与全部期货：

| 项目 | 算式 | 金额 |
|---|---|---:|
| C第一批销售 | 600×2810 | 1,686,000 |
| C第二批销售 | 399×3110 | 1,240,890 |
| C销售合计 | 上述两项相加 | 2,926,890 |
| D尾货销售 | 1×3120 | 3,120 |
| 全部销售 | C＋D | 2,930,010 |
| 全部采购 | 1000×2990 | 2,990,000 |
| 现货价差 | 2,930,010－2,990,000 | －59,990 |
| 期货累计毛损益 | 120,000－40,000 | ＋80,000 |
| 期现合并毛价差 | －59,990＋80,000 | ＋20,010 |

方法B，按批次拆分：
第一批12,000＋第二批7,980＋尾货30＝20,010。

**这两种方法是同一结果的交叉核对，不能再把两边加在一起。**

假设已确认的运作、保管、资金和期货交易等费用合计12元/吨，按全部1000吨发生；另有额外费用100元：

实际费用＝1000×12＋100＝12,100；
简化贡献＝20,010－12,100＝7,910元。

12元是本题费用假设，不是行业标准；已包含在其中的资金或期货费用不得再扣一次。
7,910是报价差价与列示费用的简化业务测算。增值税、其他未列费用和会计确认未展开，不能叫财务净利润，也不等于任一时点银行余额或期货账户可用资金。

上期所实行当日无负债结算，盈亏、保证金、手续费等会在每日结算中处理。因此＋80,000是这组假设成交从开仓到全部平仓的累计毛损益，并非D30单日新增到账80,000；不能再把每日结算盈亏重复加进去。

**七、预算8000，实际7910：差额从哪里来？**

原计划C提满1000吨，第二批400吨都按3110销售，费用只有12,000：

预算毛价差＝1000×20＝20,000；
预算贡献＝20,000－12,000＝8,000。

实际最后1吨以3120另售，比原计划3110多10元；但额外费用增加100元。

| 差异 | 对贡献影响 |
|---|---:|
| 最后1吨售价提高10元/吨 | ＋10 |
| 新增额外费用 | －100 |
| 实际比预算 | －90 |

8000＋10－100＝7910。

尾货最终卖得更贵，只能说明最终结果。D30至D45，这1吨曾经没有期货保护；若后来只能以3020卖出，尾货合并毛价差就会是3020－2990－100＝－70，比本例少100元，整笔贡献降至7810。
所以复盘同时要看**赚了多少和途中承担了什么风险**。

**八、D40的钱与发票：客户没欠款，为什么还没完全结清？**

C最终应付：
600×2810＋399×3110＝2,926,890。

假设D40财务确认已经全部到账，C未收款＝0。
但那时只开了800吨发票：第一批600吨，以及第二批200吨。

| C合同在D40 | 算式 | 结果 |
|---|---|---:|
| 已开票金额 | 600×2810＋200×3110 | 2,308,000 |
| 待开票数量 | 399－200 | 199吨 |
| 待开票金额 | 199×3110 | 618,890 |
| 未收款 | 2,926,890－2,926,890 | 0 |

800吨不是同一个单价的800吨，所以不能用800乘2810或3110算全部已开票金额。
已开2,308,000＋待开618,890＝应结2,926,890。

**618,890是C合同的待开票模拟金额，不是欠款。**
本例发票按模拟合同结算额登记；实际票面金额、税额及开票时点须以真实合同和财务税务资料为准。

U的1000吨采购发票、C的999吨销售发票、D的1吨销售发票分别核对。不能因为C结算999吨，就让U自动改为999吨；也不能把D的1吨开到C名下。

D45假设余下发票、款项、费用和异议全部核清，才可以提交结单复盘。货清、款清、票清、持仓清以及差异有处理依据，要分别说明。

**九、用五张简单台账把整笔业务接起来**

不急着做复杂系统。给业务一个统一编号，例如T-001；U采购、C销售、D销售各有独立合同号；每批再有批次号。

| 台账 | 最少字段 | 本例核对重点 |
|---|---|---|
| 合同与定价 | 业务号、合同号、签约量、已点价量、单价/公式、取消量 | C签1000、执行999、确认取消1 |
| 提货与库存 | 合同号、批次、入出库、实提量、授权、累计余量 | 1000－600－399－1＝0 |
| 收付与发票 | 应收应付、实收实付、日期、已开待开、凭证号 | D40 C未收0，但待开199吨 |
| 期货成交 | 具体合约、时间、买卖、开平、成交手数/价、关联批次、费用 | 50→20→0；399与400差1 |
| 预算实际 | 现货价差、期货累计损益、费用、贡献、差异原因 | 8000→7910，＋10－100 |

Excel/纸面任务：

1. 销售明细分三行：C-1为600吨2810；C-2为399吨3110；D-1为1吨3120。C取消的1吨记合同处理状态，不记成销售收入。
2. 期货明细分三行：卖开50手3000、买平30手2800、买平20手3100。标注第二次平仓对应400吨，管理分摊需解释1吨归属。
3. 计算销售2,930,010、现货价差－59,990、期货毛损益80,000、费用12,100、贡献7,910。
4. 单独填写D40对账：C实收2,926,890、已开2,308,000、待开618,890、未收0。
5. 写预算差异：销售＋10、费用－100、合计－90。

常用公式仅适用于本例已确认结算量、单价与款项分配：

销售额＝本批实际结算数量×本批最终单价；
库存＝累计入库－累计实际出库；
C合同剩余待处理量＝签约1000－执行999－确认取消1＝0；
C未收款＝已确认应收－已核验且分配给本合同的实收；
空头累计毛损益＝（卖开价－买平实际成交价）×平仓手数×20；
简化贡献＝现货价差＋期货累计毛损益－列示费用。

真实资料到手后，把合同、点价、成交、磅单、银行回单、发票及费用凭证一一链接到相应行；不得凭口头描述填“已完成”。

**十、文华财经观察：把成交、持仓和结算分开看**

使用模拟账户，复用能查到的一笔历史AO交易；没有历史成交就做纸面表，并注明“纸面模拟”。不用为了凑案例新开50手。

| 观察项 | 要记什么 |
|---|---|
| 具体合约 | 完整合约代码，不只写AO主连 |
| 委托 | 方向、开平、数量、委托价、状态 |
| 实际成交 | 成交时间、价、手数，是否部分成交 |
| 剩余持仓 | 已成交动作后还有几手 |
| 费用与结算 | 手续费、累计损益与每日结算的对应 |
| 业务联系 | 哪批现货已定价，哪些仍未定价或未回款 |

假设买平30手，只成交20手，则原50手空头还剩30手；不能按委托数量直接登记剩20手。
报告里将“客户点价”“期货委托”“实际成交”“实提”“回款”分别写清楚。

**十一、费曼练习：先回答，再根据答案纠错**

基础题：
1. 用自己的话解释：为什么合同、货物、期货、资金和发票要分别记？举一个“其中一项完成，其他项没完成”的例子。
2. T购入1000吨2990，C只签“同一AO合约＋10”未点价：为什么仍有售价下跌风险？本例为什么卖开50手？
3. 第一批600吨售价2810，采购2990；卖开3000、买平2800：现货价差、期货损益、合并毛价差分别是多少？
4. 客户点价2800但对应30手实际买平2803，第一批合并毛价差是多少？为什么不能沿用原12,000？

完整复盘题：
5. C第二批399吨售价3110，买平20手3100：现货价差多少？这次期货损益多少？为什么存在1吨差异？如何管理分析分摊？
6. D30之后库存与期货持仓分别多少？最后1吨在D45卖3120，现货价差及包含之前期货分摊的合并毛价差各多少？
