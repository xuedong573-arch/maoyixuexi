## 2. 一批货至少有四种属性

| 维度 | 要问的问题 | 示例 |
|---|---|---|
| 实物地点 | 货实际在哪里？ | 上游工厂、运输途中、社会仓库、下游工厂 |
| 货权与控制 | 属于谁？谁有权发出有效放货指令？ | 贸易商拥有货权，仓库保管 |
| 商业与定价状态 | 已售、预留还是自由可售？两端价格是否确定？ | 尚未出库但已为客户预留；已提走但后点价 |
| 仓单与权利限制 | 普通库存还是标准仓单？有无质押、冻结及有效期限制？ | 仓库内一部分已注册仓单 |

这四种属性会交叉。贸易商的一批货可以同时属于“社会仓库实物库存”“贸易商名下货权”和“已注册仓库仓单”。这是对同一批货的不同描述，不能相加成三批。

生产企业的普通“厂内库存”，与交易所制度中的“指定交割厂库”“厂库标准仓单”，也不能仅凭名字视为同一口径。

## 3. 常见库存名称到底看什么

| 名称 | 本课采用的含义 | 主要误区 |
|---|---|---|
| 上游厂内库存 | 氧化铝生产企业现场尚未发出的成品 | 减少可能来自发货加快，不能单独证明生产减少或终端消耗增加 |
| 在途库存 | 已实际发运、尚未到达目的地并按口径确认入库的货 | 签合同但没发货不是在途；未到厂不等于已经可用 |
| 社会库存 | 某数据机构统计的社会仓库等样本库存 | 不是天然覆盖所有仓库；是否含港口、交割库和仓单要查说明 |
| 下游原料库存 | 电解铝等下游企业现场尚未投入生产的氧化铝 | 到货只是库存位置变化，投入生产才退出本课氧化铝库存口径 |
| 隐性库存 | 常规统计未覆盖或难准确核实的货 | 是数据覆盖与可见性问题，不能凭感觉随意补一个数量 |
| 标准仓单数量 | 按交易所规则登记的标准化提货凭证数量或对应吨数 | 不能不分仓库/厂库，直接当作全行业实物库存或立即可买的货 |

真实报告里的分类不一定与本课一致。拿到数据，先记录：品种和品质、区域/样本、时点、单位、统计方法、是否含在途/下游/仓单、是否调整过样本。

同一日期发布的两份报告，统计截止时间仍可能不同；样本新增造成的数量上升，也不能直接当作实物累库。

## 4. 1000吨货流转四次，库存会不会变4000吨？

假设同一批1000吨氧化铝没有损耗，各节点已按约定完成地点状态确认：

| 观察时点 | 上游厂内 | 在途 | 社会仓库 | 下游厂内 | 该批氧化铝库存合计 |
|---|---:|---:|---:|---:|---:|
| 尚未发运 | 1000 | 0 | 0 | 0 | 1000 |
| 运往仓库途中 | 0 | 1000 | 0 | 0 | 1000 |
| 仓库入库完成 | 0 | 0 | 1000 | 0 | 1000 |
| 已送达下游并入库 | 0 | 0 | 0 | 1000 | 1000 |

每行是一个时点。不能把不同日期看到的1000吨逐行相加，声称存在4000吨。

如果货在社会仓库内从贸易商T转给客户C，地点不变：社会仓库实物仍为1000吨，只是货权记录改变。库内货转完成与实际出库是两件事。

如果下游已把这批货全部投入生产，它就退出本课的氧化铝库存口径。贸易商之间多转手一次，不会让终端多消耗1000吨。

在途期间的货权归属、风险承担不能仅凭车在哪里推断，要结合合同、交付节点和实际凭证。物理统计与货权台账分别记，再用批次号核对。

## 5. 社会库存下降，全链条却累库：完整算一次

另设独立案例，统计范围覆盖某封闭区域的全部氧化铝成品库存，四个地点分类互不重叠；两次统计时点、质量和样本一致。期间没有区域外流入流出及损耗。

| 实物地点 | 期初/吨 | 期末/吨 | 变化/吨 |
|---|---:|---:|---:|
| 上游厂内 | 8000 | 6000 | −2000 |
| 社会仓库 | 6000 | 5000 | −1000 |
| 在途 | 2000 | 3000 | +1000 |
| 下游厂内原料 | 4000 | 7000 | +3000 |
| **合计** | **20000** | **21000** | **+1000** |

看到社会库存从6000降至5000，可以说“本口径社会库存去库1000吨”。不能把它改写为“全链条去库1000吨”。

上游和社会仓库合计减少3000吨；在途和下游合计增加4000吨，最终总库存增加1000吨。局部出库和下游补库可以同时发生。

若本期氧化铝生产60000吨、下游实际消耗59000吨，供需平衡也得到：

期末库存 = 期初库存 + 生产 + 区域外流入 − 区域外流出 − 消耗 − 损耗

21000 = 20000 + 60000 − 59000

区域内部发货、到货、库内货转只改变位置或归属，不作为这条全区域公式的外部增减项重复计算。本表与D9两块库存的预告案例是分别设定的模型，不混用各自明细。

现实中如果只掌握部分社会仓库数据，就只能对该样本作判断；没有全链条数据时，不能把本题完整覆盖的假设搬进市场结论。

## 6. 仓单为什么不能另加一遍

在上表的社会仓库中，进一步假设：

| 仓库库存的另一种观察 | 期初/吨 | 期末/吨 |
|---|---:|---:|
| 社会仓库实物总量 | 6000 | 5000 |
| 其中：已注册仓库标准仓单对应货物 | 1200 | 1800 |
| 其中：未注册为该类仓单的货物 | 4800 | 3200 |

本题已明确仓库仓单对应的实物包含在社会库存中。因此期末该仓库库存是5000，不是5000+1800=6800吨。

这里同时出现“社会库存减少1000吨”和“仓库仓单增加600吨”。可能有原有普通库存注册仓单、不同状态货物进出等变化；仅凭这两项净变动，不能还原全部流转，更不能说工厂因此多生产600吨。

普通货物位于指定交割仓库，不会自动成为标准仓单。氧化铝的品牌/企业、质量、包装、单证、期限及注册手续等还需符合相应要求。[1][2]

尤其要区别两种仓单：
- 仓库标准仓单：结合仓库库存和其对应实物核对；本题中的1200/1800吨特指这一类。
- 厂库标准仓单：涉及厂库按规则履行出库供货义务，不能未经核实就视为统计日已逐吨堆存在某个社会仓库的货，再加进实物库存。

上期所氧化铝细则分别规定仓库交割、厂库交割，并规定厂库根据提货申请及生产计划确认提货安排。[1] 因此读仓单日报时，先看库点类型和表头单位，再考虑与现货调查的重叠。本文不使用真实仓单日报数值。

仓单注销也不自动等于实物已离库或已被消费；要继续跟踪实物出库和使用。具体注销与提货流程按对应规则办理。[2]

## 7. 库存少不等于你能买到，库存多也不等于能立即交付

独立业务快照：某库有1000吨我司货物，其中600吨已为有效销售合同预留；在没有其他限制的本题前提下，自由可售400吨。不能把全部1000吨再次向新客户承诺。

“市场有货”还要进一步问：客户是否接受品牌/品质？货权和放货授权是否有效？有无质押冻结？能否按交期、路线和每日发货能力运到？报价和付款条件是否匹配？

另设独立下游例子：可用现场库存7000吨，稳定日耗1000吨，静态可用天数为7天；它不代表未来7天无需采购。若新采购运输需10天，应把已确认到货计划、生产计划和安全库存一起排进时间表。在途不能冒充今天已入厂可用的原料。

库存变动是供需判断的一条证据。还需看生产/消耗变化、季节性、运输、可交易货量、价格与基差，不能从一条去库数据直接推出价格必涨。
