## 2. 氧化铝成本主要来自哪里

国际铝业协会对氧化铝精炼的介绍涉及铝土矿、烧碱、石灰等投入，以及溶出、分离、分解和焙烧等工序。[1][2] 本课不采用其平均单耗作为所有工厂的统一参数。

| 成本项 | 先查什么 | 为什么不同工厂会不同 |
|---|---|---|
| 铝土矿 | 到厂价格、品质、计价干湿基准、单耗与库存采购批次 | 矿源、运输距离、品位及工艺匹配不同 |
| 烧碱及其他辅料 | 单价、浓度/折百口径、实际消耗 | 单耗及回收利用情况不同 |
| 煤、电、蒸汽等能源 | 数量、价格、计量单位、购入或自产口径 | 能源条件、工艺效率、运行负荷不同 |
| 人工、检修、环保及其他 | 哪些随产量变化，哪些短期仍需支付 | 设备、组织与运行状态不同 |
| 折旧及其他固定项目 | 本期总额、产量分母、报告包括的费用范围 | 投资规模、资产年限和产量不同 |

自有矿也有开采、运输及其他成本，不能当成免费。便宜矿也不必然意味着每吨氧化铝成本低：若品质变化导致耗矿、耗碱或能耗上升，要算合计。

成本估算要写清时间。账面原料成本、当前采购补库成本和未来预计成本可能不同；矿价今天变化，不等于全部旧库存今天按新价重算。

## 3. 四个概念别混在一起

| 概念 | 通俗理解 | 使用边界 |
|---|---|---|
| 平均成本 | 这一期总共花的钱，除以这一期产量 | 总额和分母必须匹配 |
| 现金成本 | 从现金支出与非现金项目角度划分的成本指标 | 报告定义不统一；现金支出里也可能有短期停不掉的固定费用 |
| 完全成本 | 报告按其口径计入的全部项目 | 是否含期间费用、财务费用、运输等，必须查定义 |
| 边际成本 | 多生产一吨或一批，新增多少成本 | 看增量，不是把全部历史成本重新分摊一遍 |

另一个重要维度是**可避免成本**：在所讨论的时间内，不生产能省掉哪些支出。短期停产比较要关注它；不能把所有“现金成本”都机械看成停产即可归零。

## 4. 先拆一家厂的成本

独立模拟工厂，本期计划生产1000吨：

| 项目 | 计算或假设 | 元/吨 |
|---|---|---:|
| 铝土矿 | 单耗2.4吨×到厂矿价500元/吨，计量基准一致 | 1200 |
| 烧碱及其他辅料 | 本题假设 | 300 |
| 能源 | 本题假设 | 500 |
| 其他可避免变动支出 | 本题假设 | 300 |
| **可避免变动成本** | 合计 | **2300** |
| 本期不可避免固定成本分摊 | 200000÷1000 | 200 |
| **本题列示总成本** | 2300+200 | **2500** |

2.4只是本题单耗，不能当作全国氧化铝统一耗矿量。2300在本题被明确设为全部随产量变化、停产即可避免的支出；现实数据必须逐项核实。

固定成本的事实是“本期总额20万元”，200元/吨只是生产1000吨时的分摊。停产后不能拿0吨乘200元，认定固定成本消失。

## 5. 每吨亏100元，为什么可能继续生产

沿用上一节，假设本期1000吨都能以2400元/吨卖出；停产后20万元固定成本仍发生，没有额外停复产成本，也无其他约束。

| 项目 | 继续生产1000吨 | 本期完全停产 |
|---|---:|---:|
| 销售收入 | 2400000 | 0 |
| 可避免变动支出 | 2300000 | 0 |
| 不可避免固定成本 | 200000 | 200000 |
| **本题列示损益** | **−100000** | **−200000** |

继续生产的每吨收入先覆盖2300元变动支出，还能贡献100元，合计承担10万元固定成本。因此虽然按本题总成本仍亏10万元，亏损却小于停产的20万元。

这对应经济学中“低于平均总成本但仍覆盖相关变动支出时，短期继续生产可能减少亏损”的逻辑；它有模型条件，不是任何工厂亏损都必须继续生产。[3]

独立降价情景：若售价变成2200，继续生产损益为2200000−2300000−200000=−300000，比本题停产亏20万元还多亏10万元。

现实还需核实停复产成本、合同违约、装置安全与环保要求、现金流、关联产业链和未来价格预期。短期不停产也不代表长期能够持续亏损。

## 6. 边际成本：多做一批，到底多花多少

再设独立加产例子，不与后面的行业曲线混算：

- 生产1000吨时，本期总成本2500000元。
- 生产1100吨时，本期总成本2740000元。

新增100吨成本为240000元，故这批的平均增量成本为：

边际成本的批量近似 = 成本增量÷产量增量 = 240000÷100 = 2400元/吨

1100吨的平均总成本为2740000÷1100≈2490.91元/吨，和新增100吨的2400元不同。

如果这额外100吨都能以2450元/吨售出，且不改变原1000吨收入、不挤占其他订单、没有新增遗漏成本，那么新增贡献为：

(2450−2400)×100 = 5000元

即使原来的业务整体仍可能亏损，这额外一批也可能改善结果。这里计算的是100吨这一批的平均增量，不声称每一个单吨的严格微分边际成本都相同。

## 7. 行业成本曲线：按成本排序，还要按吨数累加

独立静态模型：只有A/B/C/D四家厂，产品品质、交货地点、税费口径相同；下表是本期可用于本模型的最大供给量，不是年产能。无库存释放、外部贸易和交付障碍。各厂在其能力区间内每新增一吨成本固定，且能按需部分生产；不计启停成本。

| 工厂 | 单吨新增成本/元 | 本期最大供给/吨 | 累计供给上限/吨 |
|---|---:|---:|---:|
| A | 2100 | 2000 | 2000 |
| B | 2300 | 3000 | 5000 |
| C | 2500 | 3000 | 8000 |
| D | 2800 | 2000 | 10000 |

横轴不是简单的“A、B、C、D”四个名字，而是累计供给吨数；纵轴是同口径单位成本。每家占据的横向宽度是它对应的吨数：

| 累计供给区间/吨 | 对应工厂 | 该区间单吨新增成本/元 |
|---|---|---:|
| 0—2000 | A | 2100 |
| 2000—5000 | B | 2300 |
| 5000—8000 | C | 2500 |
| 8000—10000 | D | 2800 |

若本期需要7000吨，从低成本向高成本依次组织供给，则A出2000、B出3000、C出2000，D不需要出货。第7000吨落在C厂成本区间，所以C是本模型的边际供给者，对应成本2500。

“边际供给者”是满足当前需求时最后还需要的一部分供给，不等于行业永远最贵的工厂。独立需求情景：
- 需要4500吨：A2000、B2500，边际落在B的2300区间。
- 需要9000吨：A2000、B3000、C3000、D1000，边际落在D的2800区间。

这展示成本排序与所需供给的关系，不直接预测现实成交价等于2500、2300或2800。现实行业报告的成本曲线还可能按平均现金成本、完全成本或年产能编制，不能未经转换就视为本题严格的短期边际供给曲线。

## 8. 成本为什么会移动，为什么不是价格硬底

沿用第4节的独立单厂模型，其他条件不变：

矿价500→540，单耗仍2.4，矿石项成本增加2.4×40=96元/吨。

于是变动成本2300→2396，本题总成本2500→2596。这是原料按新价消耗的假设；旧库存结转可能滞后。

若只这一家厂矿价上涨，只调整这家，不把全行业曲线一律平移96元。若同时出现单位消耗、产量或汇率变化，分别列示，防止重复计入。

成本线不能保证价格不跌，原因包括：
1. 看错口径：完全成本不是短期可避免成本；估计值也有误差和时间滞后。
2. 反应有时间：亏损企业可能暂不停产，已签供应仍在执行。
3. 存量货仍可能销售：旧库存销售决策不等于今天重新生产一吨的决策。
4. 需求和外部供给会变化：进口、库存释放、区域流动都能改变边际供给者。
5. 成本自身会降：矿、碱、能源价格和工艺效率变化会改变曲线。

研究中的“成本支撑”是带条件的供给反应线索。要继续验证是否减产、减多少、何时影响可售量、是否被其他增量抵消；不能仅凭价格低于某条成本线认定不会再跌。下一课D12重点练这个反馈链。

## 9. 接回贸易商：工厂成本不等于你的采购价值

另设独立贸易案例，所有金额同为不含可抵扣税的模拟口径：

- 拟采购厂价2400元/吨。
- 已核实可匹配的下游售价2500元/吨。
- 运费60、其他费用10、资金成本15元/吨。
- 公司希望本笔列示贡献至少20元/吨。

按2400采购，列示贡献 = 2500−2400−60−10−15 = 15元/吨，未达目标。

相应采购厂价上限 = 2500−60−10−15−20 = 2395元/吨。

即使有人估计工厂完全成本2500，也不能据此说2400采购一定划算。工厂的成本、厂商愿意成交的底线、市场替代报价和我司采购上限是不同的数；数量、品牌、货权、交期、收款和信用仍要核查。

上限2395不是市场报价或对手必须接受的价格，也不构成实际采购承诺。资金15只是题设，实务应按付款/回款计划计算。

## 11. 文华30分钟：价格区间与波动观察

1. 选择一个仍有效的具体AO月份，记录完整合约代码、日期时间、数据来源和单位。
2. 固定同一合约、同一日线窗口，记录最近5个已完成交易日的开高低收、区间最高与最低。夜盘按交易日归属记录。
3. 单日振幅金额用当日最高−最低；如计算百分比，明确分母，例如昨结。5日区间最高−最低不等于5日累计收益。
4. 例如某独立模拟交易日高2660、低2580，区间金额80；若前一日结算价2600，以昨结为分母的振幅为80÷2600≈3.08%。收盘价未给出，不能说该日上涨3.08%。
5. 本题不把文华AO报价直接减去前面的不含税成本，认定工厂利润。还缺税费、地点、品质、时间及现货/期货基差等可比条件。
6. 无真实行情权限或不在交易时段，可标注历史/纸面数据；不能补造实时截图、成交或持仓。今日不要求新增仓位，也不因接近成本估计而做模拟抄底单。

## 12. 费曼输出：先答1—4题

1. 厂价2400、可避免变动成本2300、本期固定成本20万元、产1000吨：继续生产和停产分别亏多少？为什么继续生产可能更合适？
2. 成本250万元生产1000吨、成本274万元生产1100吨，新增100吨的平均增量成本是多少？它与平均总成本有什么区别？
