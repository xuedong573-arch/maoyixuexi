## 2. 先搭业务框架

一笔交易至少有七项独立状态：

| 状态 | 需要回答 | 常见证据 |
|---|---|---|
| 合同与批准 | 双方究竟同意什么，公司允许怎样执行？ | 有效约定、合同版本和内部审批 |
| 货权与授权 | 谁能支配这批货、谁有权发出放货指令？ | 货权/仓库确认、有效提货授权 |
| 实物与验收 | 实际装多少、到多少、是否有质量数量异议？ | 磅单、出库记录、签收验收 |
| 定价 | 哪端固定、哪端仅锁基差、谁何时点价？ | 计价条款与有效点价确认 |
| 期货 | 需要什么风险方向，委托和实际成交多少？ | 批准方案、委托回报、成交与持仓 |
| 收付款 | 应收应付多少，实际到账及分配多少？ | 银行/票据记录、财务分配和结算单 |
| 发票与结单 | 应开/应取、已开/已取及剩余事项是什么？ | 发票、费用单、核销和差异待办 |

合同签了不代表货权已取得，发出提货指令不代表仓库已完成，挂单不等于成交，开票不等于现金到账。每项都要有自己的完成依据。
采购/销售两份合同独立执行，一端有变化不能擅自替另一端改条款。熟客同样要满足有效约定和公司批准；授信额度获批不能代替每批放货核验。

## 3. 主案例：U→T→C

- U：上游氧化铝工厂。
- T：你所在贸易公司。
- C：下游客户。
- L：由T委托的物流公司。

T从U工厂自提，再由L直接送到C厂；T不另租仓。本题只讨论普通现货交付，不把货物当作已注册标准仓单。

| 条款 | 采购U→T | 销售T→C |
|---|---|---|
| 原合同量 | 1000吨 | 1000吨 |
| 固定单价 | 2500元/吨，出厂 | 2580元/吨，到厂 |
| 原货值 | 2500000元 | 2580000元 |
| 付款 | T第0天预付原合同全款 | C第0天先付原销售额20%；余款验收后30个自然日付 |
| 提货/交付 | T委托L自提 | 约第5天到厂验收 |
| 其他条件 | 品牌、批次、质量、计量、授权和异议均已有效约定 | 与客户要求相匹配 |

本题为了练应收，明确假设C账期、额度和本批信用放货均已批准且无逾期；不是公司日常必须先放货后收款的规则。
T承担运费40元/实际吨和其他物流服务费5元/实际吨，第5天支付；无仓储、无损耗、无其他费用。资金年率假设6%、365天单利。
金额采用统一简化报价/现金及费用管理口径，不展开增值税收付与正式不含税利润，计算结果称简化贡献，不是财务净利润。

### 为什么本例不机械加空头

对应数量有效固定采购价2500、销售价2580，未出现另一端尚未定价的假设。仍有履约、质量、数量、信用和现金风险，但不能仅因为采购了1000吨就再自动卖开50手。
真实业务若已有相关持仓，要核对其来源和是否仍需保留；本题没有新增期货不证明任何真实账户已经平仓。

## 4. 时间轴：先核条件，再记实际

| 相对日期 | 本题实际事件 | 需要留下的记录 |
|---|---|---|
| 第0天 | 有效合同/批准就绪；C先付516000；随后T向U付2500000 | 到账、付款与合同分配，U收款及后续放货条件 |
| 第5天 | T有效委托L，U实际交999吨，C验收999吨；T付物流费44955 | 授权、出库/磅单、运输、验收与费用 |
| 第8天 | 上下游各自确认取消未执行1吨；U实际退2500 | 两份结算/变更与退款到账 |
| 第10天 | 核对发票和货款，仍有独立待办 | 已开/待开及已收/未收分别登记 |
| 第35天 | C尾款2061420到账，其他遗留事项分别核验 | 回款、发票、异议、费用和业务核销 |

C预付：1000×2580×20%=516000元。预付原合同全款20%不是最终999吨货值必须重新计算的20%；本题双方确认实际516000全额抵最终货款，不另退预付款差额。

提货前要核合同剩余量、货物批次质量、付款或有效授信、T对L的委托、司机车辆与U放货确认。临时换车要有效更新并核销旧授权，不能因为车已到厂就放货。
付款、货权、风险转移和实际交付时点按本题约定/凭证分别确认，不能只凭银行回单认定已有1000吨实物。

## 5. 999吨的那1吨去哪里了

本例明示：U只交999吨；剩余1吨从未交给T，T未取得这1吨。没有损耗和磅差。
第8天U/T确认取消采购剩余1吨，T/C另行确认取消销售剩余1吨。两份有效确认之后，两端剩余待执行量才各为0。

| 数量状态 | 采购合同 | 销售合同 |
|---|---:|---:|
| 原合同 | 1000 | 1000 |
| 实际交付/验收 | 999 | 999 |
| 有效确认取消 | 1 | 1 |
| 尚待执行 | 0 | 0 |

因此本例没有“库存还剩1吨”，也不能叫作“运输损耗1吨”。
如果U已交1000、C只收到/提走999，T可能还有1吨待处理，必须查其实际位置和权利。这与本题事实不同。
如果只有U同意取消而C仍要求补足，销售义务仍在；如果C同意取消而U要求T继续提，采购义务也不能自行删除。

## 6. 货款怎么结

| 项目 | 采购U | 销售C |
|---|---:|---:|
| 最终结算货值 | 999×2500=2497500 | 999×2580=2577420 |
| 第0天实际收付 | T付2500000 | T收516000 |
| 后续余额 | U应退2500 | C尚欠2061420 |
| 本题后续实际 | 第8天退2500到账 | 第35天尾款2061420到账 |

退款2500只是原先多付的钱回来，不是额外盈利。已经按2497500计最终采购后，不能再把2500加一遍利润。
应收2061420在第35天实际到账之前一直保留。结算确认和开发票都不把它自动清零。
若U承诺退款但没实际到账，退款现金状态仍未完成；合同取消和实际退款分开记。

## 7. 票和款分别看

第10天假设已取得U对应999吨的采购发票，已向C开800吨销售发票；这是练习台账的状态，不据此判断真实开票时点合规，实际按适用规定办理。

| 第10天销售状态 | 金额/数量 |
|---|---:|
| 最终销售应收 | 2577420元 |
| 已收现金 | 516000元 |
| 未收货款 | 2061420元 |
| 已开销售发票 | 800吨，2064000元 |
| 待开销售发票 | 199吨，513420元 |

核对：
- 516000+2061420=2577420，是收款线。
- 2064000+513420=2577420，是发票线。

待开票513420不是客户欠款513420。第35天如果现金已收齐但199吨仍待开，未收货款为0、待开票仍513420；还有票务待办。反过来，票已开齐也不说明货款已回。
收到承兑的独立变式中，还需核对公司接受标准、承兑人/权利状态、到期和贴现等，不能直接替换本题银行现金到账记录。

## 8. 先算贡献，再看资金是否够

实际现货买卖价差：
2577420−2497500=79920元。

实际物流费用：
999×(40+5)=44955元。

扣资金前简化贡献：
79920−44955=34965元，即999×35。

原计划1000×35=35000元不能直接记作最终值；本题实际执行结算999吨。

### 分段资金：进阶计算

客户第0天预付款先到账，之后T付款；第5天T支付物流；第8天U退款；第35天C尾款回收。

| 占用期间 | 净垫资本金/元 | 天数 |
|---|---:|---:|
| 第0—5天 | 2500000−516000=1984000 | 5 |
| 第5—8天 | 1984000+44955=2028955 | 3 |
| 第8—35天 | 2028955−2500=2026455 | 27 |

资金成本：
(1984000×5+2028955×3+2026455×27)×6%÷365
=11625.39元。

资金后简化贡献：
34965−11625.394521=23339.61元。

资金成本是本题管理模型，不凭此声称银行已经扣息；真实借款、付款和税费有不同条件时另建现金表。
本题峰值垫资2028955元。若可动用资金只有200万元，首日虽然够，第5天仍缺28955元；需要在发生前解决条件，不能用最后能赚钱替代中途资金安排。

## 9. 独立点价分支：锁基差、点价与期货成交

本节全部另设：不沿用主案例的999吨、价格、款项、发票或持仓。假设另有1000吨采购最终价已固定、销售以同一具体AO月份加固定基差计价的业务；仅作等吨数、同月、同幅价格变动的纸面模型，不展开税后敏感度和费用。

本题设定期货台账已有50手匹配空头。AO交易单位20吨/手见官方细则[1]；这里的50手是纸面已有量，不要求学员开仓。

| 业务状态 | 未定售价吨数 | 本题对应空头目标 |
|---|---:|---:|
| 客户只签基差合同，还没点价 | 1000 | 50手 |
| 客户有效点价600吨，另400吨未点 | 400 | 20手 |

由50手到20手，本模型需要匹配减少30手空头，方向是买入平仓。但必须将“计划买平30手”和“实际成交30手”分开。
如果只实际买平成交20手：
- 剩余实际空头30手，对应600吨；
- 尚未定售价只有400吨；
- 本模型相对于目标多出200吨空头，即10手。

要把差异登记并按授权方案处理，不把未成交10手记成已完成；如已有未成交委托，还要核查其状态，避免重复委托。成交与交易结果以交易所记录为准[2]。
本题只识别数量错配，未提供开平价格，不计算期货盈亏，也不宣称当下可无成本补齐。

点价单还需写谁有点价权、对应合同与合约、数量、报价/成交基准、有效时间、部分成交和未成交处理。现货点价的有效时点和期货成交能否完全同步，按约定及真实记录核验。
客户交货、付款、点价和期货平仓可能是不同时间，不能凭其中一项完成把其余全部勾完。两端价格已经固定的主案例也不能拿本分支的50手套回去。

## 10. 怎样判断业务能结单

逐项确认，而不是只写“货发完了”：
- 数量：两端实际量、取消量、剩余履约量都明确；
- 交付：授权、运输、验收及质量数量异议有结果；
- 定价：两端最终价或未定价余量明确；
- 期货：如有对应持仓，实际成交、剩余持仓及残余风险已核对；
- 货款：应付、应收、退款与实际分配核销；
- 发票：应取/已取、应开/已开分别核验；
- 费用：物流、仓储、资金与其他费用按事实确认；
- 复盘：预算实际差异、凭证、责任人和待办可追溯。

主案例未取得真实材料，以上均是教学状态，不能拿来宣布真实公司业务已结清。D3—6未提交的输出不因D7开始而自动验收。
