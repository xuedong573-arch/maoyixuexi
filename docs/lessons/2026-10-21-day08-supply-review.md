## 1. 从D7的一笔合同，走向D8的供给判断

D7回答一笔采购如何交付、结算。D8开始回答：为什么某个时期市场能提供的货变多或变少？一家工厂的变化，能影响你哪笔业务？

今天的目标不是听到“检修”就猜涨跌，而是完成四个动作：
1. 明确产品、地区、工厂/装置、统计期间和单位。
2. 估算相对基准实际增减多少吨，辨认计划、实际和不确定项。
3. 汇总其他工厂变化，防止重复计算。
4. 从生产量追到可新售、客户认可与按交期可交付量。

五模块各30分钟：理论、案例、Excel/纸面、文华观察、费曼。

## 2. 产能、产量与可采购量是不同的数

| 名称 | 本课理解 | 业务中要追问 |
|---|---|---|
| 建成产能 | 已建成装置在给定条件下的生产能力规模，常以吨/年表示 | 是否建成、产品是什么、统计时点和口径？ |
| 运行能力 | 本题正在运行装置对应的能力规模 | 开着哪些线、开多久、负荷是多少？ |
| 实际产量 | 一个明确期间实际生产的产品数量 | 是本周、本月还是全年，是否为合格产品？ |
| 可对外新售量 | 扣除内部供应、既有销售安排等之后，尚可承接新销售的货 | 已分配、已售未发、可自由出售各多少？ |
| 按要求可交付量 | 质量/品牌、地点、交期及执行条件符合客户要求的量 | 能否订车、放货、运到，资金和信用条件能否满足？ |

年产能120万吨，不能直接认定每月有10万吨可以卖给你。
“除12”至多是某模型的月度能力折算，真实产量还受运行天数、负荷、检修、原料能源、合格品和爬坡等影响；产出的货也可能早已分配给内部或长协。

自有矿、进口矿等原料能否持续到厂，工艺/装置能否稳定运行，都要核实。原料涨价不自动等于当天少产，利润较高也不保证马上增产。
新项目从宣布、建设、投料、爬坡到合格产品及发运，是不同状态；不能把宣布的年产能直接加为当月产量。

## 3. 开工率：先找分子和分母

独立指标模型：样本10家，本月整月7家开工；建成年化能力120万吨，运行装置对应年化能力90万吨；范围整月不变，实际月产6万吨。
本题粗略按年化能力除12折算：总月度能力10万吨，运行装置月度能力7.5万吨。这里是教学数量模型。

| 指标 | 本题计算 | 结果 |
|---|---|---:|
| 企业家数开工比例 | 7÷10 | 70% |
| 产能口径运行比例 | 90÷120 | 75% |
| 全部能力的数量利用比例 | 6÷10 | 60% |
| 运行装置的数量负荷 | 6÷7.5 | 80% |

四个数同时成立，因为回答的问题不同。不能把70%与80%直接比较，就说两份报告互相矛盾。
看到报告写“开工率80%”，要查企业/生产线还是产能口径，是否按期间加权、样本和分母有没有改变。
国家统计局解释产能利用率为实际产出与生产能力的比值，分子分母口径须一致；我国官方工业调查采用价值量指标[1]。本课吨数模型不能冒充其发布的统计结果。

另一个独立算术例子：同口径比例75%→80%，增加5个百分点，相对增幅5÷75≈6.67%。期间、样本或计算方法改变时，不直接把差值当作真实改善。

## 4. 一条检修消息，怎样变成吨数

张经理说：“下周检修，后面可能不好拿货。”

先按六个问题核实：
1. 哪个具体工厂、哪条生产线、哪种产品/牌号？
2. 是计划、已停、降负荷，还是正在复产？信息来自哪里？
3. 正常产出多少，这次实际影响日产多少，其他线是否继续运行？
4. 预计多久，与本研究期重叠几天？
5. 原预测是否已经计入？这次是新增、延期还是提前结束？
6. 工厂库存、其他装置、跨区/进口到货和发运安排能否缓冲交付？

独立检修例子：全厂正常日产2000吨，其中本次检修生产线实际减少800吨/日，停10天；其他线照常，无补产。

本次少产 = 800×10 = 8000吨。

不能用2000×10算20000吨，因为本次没有停全厂。
若10天中只有5天落在本月，则本月影响4000吨，另外4000吨属于下个月。研究期不同，结果可以不同。

复产也要按实际增量算。若恢复后两天各多产300吨，后三天各多产600吨，本段增加300×2+600×3=2400吨；不能假定五天都已满负荷。这个爬坡例子独立于下一节B厂的3000吨假设。

## 5. 主案例：A检修了，样本总产量却没减少

沿用旧D8主模型，便于对照。设一个完整月份的样本基准产量60000吨，尚未计入下表四项；同一产品、期间和样本，事件互不重叠。假设各项在本情景中全部按表兑现。

| 事件 | 题设条件 | 相对基准影响/吨 |
|---|---|---:|
| A新增检修 | 实际影响800吨/日，10天 | −8000 |
| B复产 | 本月实际新增600吨/日，5天 | +3000 |
| C新装置 | 公告年化24万吨，本月合格增量只计1000吨 | +1000 |
| D其他工厂提产 | 本月实际增量4000吨 | +4000 |
| **合计净变化** | −8000+3000+1000+4000 | **0** |

调整后的本期样本产量仍是60000吨。

A的减产在模型中成立，但其他增量抵消了它。这个结论只针对样本总量；品牌、地区或某周交付窗口仍可能出现缺口。
C的24万吨/年是能力概念；24万÷12=2万只是能力折算，不是本月实际产出。本题只计给定的1000吨合格增量。

不能从样本净变化0直接推断全国供给不变、我司可采购量不变或市场价格不变。

## 6. 修正预测最容易错在“重复扣减”

如果60000基准本来已经包含A停10天的影响，再减8000就重复了。事件表要有“已计入基准？”一栏。

独立延期模型：另一个原产量预测为52000吨，已包含某线影响800吨/日、停10天；后来确认总停15天，其他条件不变。
本次新增影响只有额外5天：
800×(15−10)=4000吨。
修正预测为52000−4000=48000吨，而非再次扣完整15天的12000吨。

同一条检修不能既在产量事件表扣一次，又因开工率下降另扣一次。同一厂同一装置同一事件被多人转述，也不能计成多个减产事件。

待核实消息单独登记和做明确标注的情景，不能冒充已确认总量；未知影响也不等于已经确认影响为0。记录消息发布日期、实际发生日期、来源、参数和更新责任人。

## 7. 从60000吨产量，追到可谈的2000吨

另设独立货源筛选模型：某已完成生产周期实际合格产量60000吨，其中35000吨供内部、20000吨履行既有长协，安排不重叠；不考虑期初库存及其他来源。

尚可对外新售 = 60000−35000−20000 = 5000吨。

5000吨中客户认可品牌/品质的只有3000吨；其中未来7天能按约定路线运到客户的只有2000吨。

| 筛选层次 | 数量/吨 |
|---|---:|
| 已实际生产 | 60000 |
| 尚可新售 | 5000 |
| 客户认可品牌/品质 | 3000 |
| 未来7天符合交期 | 2000 |

这是逐层筛选，不能相加成70000吨；2000吨也不是我司已取得货权或已经成交。
采购前继续核品牌与实际生产地、批次/质量、货权限制、报价与计价月份/基差、付款/授信、装运放货及到厂全程成本。

若贸易商另有1500吨旧库存可释放，这是独立来源，先确认与上述货是否重叠；即使完全独立、可售可交，也只能在相应可用货量中另计，不能把当期生产量60000改成61500。
如果1500吨也全部符合未来7天条件，本题对应可交付来源为2000+1500=3500吨；这是独立扩展情景，仍非我司已签采购量。

进口已签、已装船、已到港、已清关可提各有状态；跨区货还要核时间和客户接受度。厂库资格或标准仓单余额不是当周实际发货承诺，不能仅凭主体在官方名单就认定有货可卖。

## 8. 供给消息如何影响采购判断

本课给的是供给证据，不直接给买卖结论。仍要连同需求、库存、价格/基差、资金、销售和交付条件判断。

独立封闭区域模型：原供给10000、实际消耗10000；后来供给9000、消耗8000，忽略外部流动与损耗。
供给下降1000，消耗下降2000，仍会形成供给比消耗多1000的库存增量。看见减产，不能单凭这一条说价格必涨。

还要查市场是否已经知道消息、实际减产何时影响可售量、低库存还是高库存、其他来源是否替代。下一课D9进一步区分生产消耗、采购到货和补去库。

给主管的合格表达例子：
“样本月度模型净变化0，其中A−8000被B/C/D增量抵消。但客户认可品牌未来7天可交量只有2000，仍需核实本周装运与替代货源。尚不能凭A检修决定采购；价格、销售、资金和来源证据待补。”

## 9. 今天三张表

1. **指标口径表**：来源、日期、品种/地区、样本、分子/分母、单位、方法和结果。填第3节四种比例。
2. **供给事件表**：企业/线、事件、计划/实际/待核、影响日产、研究期内天数、净增减、已入基准否、发生日/消息日、证据和更新。复算第5—6节。
3. **可采购货源表**：生产/库存来源、已分配、可新售、客户认可量、按期可交量、是否重叠、货权/付款/物流等待核项。填第7节，扩展旧库存时明确单列。

无真实工厂资料，用本课数据标“教学模拟”；不以填完表格代表完成真实询价或已拿到货。纸面张经理回复不发送给真实对手。

## 10. 文华30分钟：盘面观察不能替代工厂证据

选一个仍有效的具体AO月份，记录完整代码、数据日期时间、价格、成交量、持仓量及单位/统计口径。
比较两个可比时点，尽量固定同一合约。若算一段时间成交量，确认是否为同一交易日累计值，跨交易日可能重置，不能机械相减。
如有行业消息，分别记录消息发布时间与事件发生时间，避免把两者混为同一天。

独立纸面数据：价格3000→2960、持仓100000→110000，只能说明该口径价格下跌、持仓增加；不能据此证明某厂减产，也不能把持仓手数当现货库存或终端采购。

将观察表分成“盘面事实、产业证据、推测与待核”三个栏目。无可靠行情/工厂信息，注明缺失或历史/纸面；不编造实时数据、不新增仓位。期权暂不讲。

## 11. 费曼题：先答1—4

1. 年产能120万吨，为什么不能直接说每月有10万吨能卖给你？请按产能、产量、可新售和可交付四层解释。
2. 指标模型10家开7家、建成120万/运行90万年化、实际月产6万，按本题除12假设，四种比例各是多少？分母为什么不同？
3. 全厂日产2000，本次只影响800吨/日、停10天，无补产时少产多少？只有5天落在本月，本月影响多少？
4. 基准60000未计四项事件，A−8000、B+3000、C+1000、D+4000，调整后产量多少？能否因此认定价格不变？
5. 如果基准已经包含A检修，再扣会错在哪里？独立52000预测从停10天延至15天应修正到多少？
6. 60000中内部35000/长协20000，可新售多少？为什么与认可3000、7天可交2000不能相加？
7. 独立旧库存1500满足同交期，能否改写生产量？单独可交来源合计多少，还要排查什么？
8. 原供给10000/耗10000、后来供给9000/耗8000，库存方向如何？为什么减产不能单独推出必涨？
9. 同口径75%→80%增加多少个百分点、相对多少？若样本变了能否直接比较？
10. 模拟回复“下周检修、后面缺货”的张经理，100—150字，至少追问装置/产品、实际影响、时间、是否已计入原计划、库存与可发货量。不给实际采购承诺。

提交后按单位、分母、研究期、基准防重和可采购条件评估。D7及旧D8待补不自动通过，已完成仍2/30；下一课D9需求复习，D12—14尚未学及其他待补全部保留。
