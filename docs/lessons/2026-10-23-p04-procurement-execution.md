# P04｜采购执行：提货、验收与异常

> 课程：10课精简版 v2.1  
> 日期：2026-10-23（北京时间）  
> 当前：P04进行中、待作答；P01—P03保留已讲待检。  
> 本课输出：一份提货执行与异常跟踪记录。所有主体、指令、金额和合同规则均为模拟资料。

今天练三个重点：确认真正可提货再安排车辆；按合同、工厂、批次控制执行；把出厂、到仓、验收及结算数量分别记录并处理差异。

## 1. 本课进入模拟执行分支

为练习执行，新增以下明确的课堂前提：采购合同已有效签署，本批资金、信用和审批条件已经另行落实；初始保证金和首批货款已按约核实到账。这只是本课情景设定，不表示用户已通过P01—P03，也不代表实际发生了采购、付款或提货。

- 合同：PX04，氧化铝3000吨，固定含税2710元/吨。
- 供方B为合同卖方，甲、乙工厂为约定货源及提货地。
- 原分配：甲厂2000吨，乙厂1000吨；三批各计划1000吨，原定前两批甲厂、第三批乙厂。
- 本课采用P03基准付款分支：保证金81.3万元留末批抵货款；首批271万元已核实付给B，累计352.3万元。
- 我方委托物流自提，送到我方已签仓储协议并指定的W仓；W仓负责按委托点收和记录，品质验收按合同及授权安排进行。
- 本课不采用P03最终2900吨的减量变式，合同数量仍为3000吨。相应立项、资金及信用条件在本课执行分支中另行满足。
- 第一天先安排第一批，不一次下达全合同3000吨的车辆放行额度。

## 2. 提货启动：钱到B，货还需由工厂确认可提

首批付款后，B通知：“钱收到了，明天安排车辆去甲厂。”

但甲厂经核实的业务渠道回复：“B的该批货款尚未落实，当前没有给你方生效的可提额度。”

两条信息描述不同环节：我方向B付款已经完成，而B对甲厂的供货安排尚未落实。不能把付款回单直接当作工厂放行凭证。

启动提货应把以下事项串起来：

| 检查环节 | 必须落实的问题 | 对应记录 |
|---|---|---|
| 合同和付款条件 | 本批是否在合同、信用与资金授权内，钱是否真实到正确主体 | 生效合同/变更、付款审批、付款及到账核对 |
| 工厂可提确认 | 工厂是否认可给我方/授权方的本批数量、品种、批次及有效期 | 经核实渠道取得的可提货确认、提货额度和限制 |
| 我方提货授权 | 谁能安排物流、哪些车辆能提、本批最大可提多少 | 有效提货委托、派单及车辆报备 |
| 预约和接收 | 工厂何时装车、需要什么手续，W仓能否接收 | 装车预约、车辆审核、收货仓预约 |
| 发运和验收 | 每车装了多少、什么时候离厂、何时收到、是否存在差异 | 出厂磅单、运输记录、到仓磅单、签收/验收及异常记录 |

“可提”记录要能定位到合同或批次、品种、数量、提货主体及有效期。仅有供方口头承诺、过期提单或来源不明截图，不足以直接安排本题的放行。

### 异常一：付款后提货启动受阻

本题公司流程要求在工厂可提及接收安排确认后，才向物流下达可执行派车指令。当前应：

- 暂缓尚未出发的派车，已在途车辆核实后安排等待或调整，记录可能产生的费用及依据；
- 向B取得卡点原因、补救安排与确定时限，要求其落实甲厂可核验的放行条件；
- 把已付金额、可提缺口、预计延期及对后续交付的影响报告有权人员；
- 并行评估约定内替代工厂、分批放行或其他履约补救；按合同和授权确认成本、时间及责任。

不能只靠“再付一笔就能放货”解决。本题已有付款给B，若另向甲厂付款，会涉及付款路径、重复支付、原款归属和合同关系变化，必须另核方案及审批，不能由司机或业务员临时决定。

此时台账应如实写：已付款、甲厂可提未落实、尚未发运。已付不等于已取得在库货物，也不能在没有相应证据时提前释放全部供应商信用占用。

## 3. 分工厂执行：本批调度与合同总量同时控制

B提出：“先从乙厂提1000吨，把原第三批提前，甲厂的两批后面再提。”

这条建议可能是履约补救路径，但要先核：

- 乙厂是否确实属于有效约定货源，品牌、质量及客户适用性是否一致；
- 乙厂能否向本合同提供可核验的1000吨可提额度，不能重复占用其他业务的额度；
- 提货日期、运输路线、到仓预约及费用是否变化，谁承担、如何确认；
- 依合同和权限完成双方必要的变更确认及内部调度审批，再替换旧派单，避免甲乙同时放同一批。

不能仅因合同有“山东地区”就推定所有工厂及新增费用都可随意变化，也不一概认定任何调整都必须另签某一种固定形式文件。要按有效合同、实际变化与授权要求确认。

### 本批提货指令应含哪些字段

同一业务号PX04下，至少写清：

- 指令编号、合同/批次号、提货主体和授权物流；
- 工厂名称及具体提货点，品种、品牌/批次、计划数量、累计可提上限、有效期；
- 车辆报备清单、装车日期/预约、交付到W仓的地址和接收安排；
- 计量及单据要求、异常联系人、指令签发权限、变更/撤回记录。

指令是本批业务授权，不是任意车辆可以提完整3000吨的通行证。实际报备内容采用工厂认可格式；课堂不填写真实司机、身份证或联系方式。

## 4. 后续情景：乙厂发出1000吨，W仓只收到996.8吨

为继续练习，现明确假设：上述乙厂调整及审批、可提确认、物流授权已落实；第一批实际从乙厂出厂。所有车辆已到W仓，尚未完成最终差异及结算确认。

| 数量口径 | 本题记录 |
|---|---:|
| 本批计划提货量 | 1000吨 |
| 乙厂出厂磅单汇总量 | 1000吨 |
| W仓实收净重汇总量 | 996.8吨 |
| 出厂与实收差异 | 待计算 |
| 最终验收/结算数量 | 待按合同与复核结果确认 |

### 先明确本题合同规则

- 采购结算以双方确认的出厂净重为依据。
- 到仓实收与出厂记录差异超过出厂净重的0.2%，启动复核。
- 0.2%只用于触发复核，不表示以内差异当然免赔，也不表示超出部分当然由某一方赔偿。
- 发现差异须在收货后24小时内先书面通知B和承运方；复核或第三方检验的进一步时限、程序按约定执行。
- W仓如实记录实际实收和待验/差异状态，不凭计划数量虚增库存。
- 超差不自动改用到仓重量结算；责任和金额需结合计量、交付、运输、合同及证据确认。

以上均是本课假设，不是氧化铝行业统一损耗标准、法定期限或结算惯例。

差异计算：

差异吨数 = 出厂净重 − 到仓实收净重。

差异率 = 差异吨数 ÷ 出厂净重 × 100%。

触发复核的比较基准是1000吨×0.2%。

### 先留证据，再确认原因和责任

复核时把同一批、同一车辆的记录对应起来：

1. 核出厂与到仓磅单、车号、批次、时间、毛皮净重、是否漏单/重单或混入其他批次；
2. 核途中运输、装卸、封识及到仓异常记录，必要时按程序复磅、查验计量条件；
3. 向合同各方发出及时通知、保留签收及异议记录，按约定共同核查；
4. 依据证据和合同确认数量、责任、费用及后续结算处理，分别追踪B与承运方事项。

不应仅凭差额就断言供应商少发、司机损耗或仓库错误。若需要补货、退款或索赔，应区分采购价款、运输责任及额外费用，避免重复主张或提前记作已确定应收。

### 质量验收怎样衔接

点收重量与质量验收分别记录。发现质量疑问时，按合同及时提出异议、封样留证、开展约定检验或复检，物料标明待验/受限状态。数量签收不自动证明质量验收通过；在结果和授权未明确前，不把待验货随意混用或当作可售库存。

本课只设置启动卡点和数量差异两项异常；不额外布置质量纠纷案例。

## 5. 台账要留下事实与待决事项

经本课明确假设的乙厂发运后，可以先这样记：

| 跟踪项 | 当前记录方式 |
|---|---|
| 合同总量 | 3000吨，尚无减量确认 |
| 甲厂计划/已出厂 | 2000吨 / 0吨 |
| 乙厂计划/已出厂 | 1000吨 / 1000吨 |
| 按出厂记录尚未发运 | 2000吨 |
| W仓实际点收 | 996.8吨，附待验/差异状态 |
| 本批出厂与实收差异 | 单独列待核，不虚构在库或已确认赔偿 |
| 最终合同履行/结算量 | 依合同与复核结果确认，暂不把出厂量直接认作结单结果 |

“剩余未发运”“到仓实收”“最终未履行量”不是随意互换的字段。不能用3000减到仓数后，把全部差额都认作工厂尚未发货；也不能拿出厂1000抹掉仓库实际只收996.8的事实。

异常记录至少写：发现时点、合同/批次、事实与数量金额、证据、已通知对象、责任人、下一动作、截止时点及处理结果。责任未确认就标待核，不提前归责。

## 6. 你的三个问题与主要输出

1. **提货启动：**B确认收款、甲厂却没有生效可提额度时，你是否派车？列出先要落实的三项信息或凭证，并写明向谁核实、落实前如何安排物流。
2. **分厂调度：**改由乙厂先提1000吨，需要核哪些变化并留下什么确认？请写一条简短提货指令，包含合同/批次、工厂、数量上限、授权物流、收货点及有效期；乙厂本次发1000吨后，甲乙剩余计划各是多少？
3. **数量验收：**出厂1000吨、到仓996.8吨，差异吨数及差异率是多少，是否触发0.2%复核？W仓先记多少实收，采购最终结算量能否立即确定？提出两项证据核查与一个必须及时完成的动作。

一份输出可按以下格式：

> 提货启动意见：____；待落实条件/凭证：____。  
> 本批指令及工厂配额：____。  
> 出厂/实收/差异/待确认结算数量：____。  
> 异常下一动作、责任人、截止时点：____。

答案可先口述，再补简表。本课不要求另写完整物流合同，也不发出真实指令或联系任何人。
