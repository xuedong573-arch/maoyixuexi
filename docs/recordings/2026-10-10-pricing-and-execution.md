# 录音15、16：定价、执行与预算教学框架

> 整理日期：2026-10-10
> 来源：学员提供的两份录音转写；未重新识别原始音频。
> 作用：补充课程案例与验收，不代表学员已掌握或结课。
> 品种校对：转写混用“氧化锂/氧化铝”；结合 AO、氧化铝厂、电解铝下游，课程暂按氧化铝整理，原始说法及公司、工厂名称仍须核对。

## 1. 两份录音的教学重点

录音15侧重交易模式：历史价格记录 → 月均价/固定价/盘面加基差 → 点价与提货先后 → 采购销售物流 → 库存与交割概念 → 税费预算；期权仅作为延伸话题。
录音16侧重落地方法：一笔已完成业务全链复盘 → 品牌/工厂/区域/流向 → 到厂综合成本 → 承兑和账期 → 数据来源 → 台账。

合并前次业务流程录音，形成五条训练线：
1. 定价：价格来自哪个来源，什么月份、地区、质量、税费与交付口径？
2. 执行：合同、货权、提货授权、物流、实际数量、双边结算与票款货。
3. 风险：哪些采购或销售价格已经固定，哪些未定价，现货与期货数量/时点如何匹配？
4. 核算：含税现金流、不含税成本收入、资金/贴现/物流/仓储、期现合并损益。
5. 数据：每日价格表、区域物流表、业务台账、期货成交表相互关联，支持复盘。

## 2. 定价模式与点价流程

| 模式 | 示例（假设值） | 签约时固定什么 | 仍待确认什么 |
|---|---|---|---|
| 固定价/一口价 | 出厂自提2710元/吨 | 总单价 | 运费、质量、交付、付款等口径 |
| 网价月均价公式 | 指定来源山西某月均价+10 | 来源、月份、均价方法和升贴水 | 月均价最终数值；送到报价还需物流条件 |
| 期货加基差 | 指定完整年份月份AO合约点价+20 | 合约与基差 | 有效点价、费用和最终单价 |
| 按提货先后区分的点价 | 先点价后提货，或先提货后点价 | 合同所约定的权利和期限 | 实际点价时点、未点价处理及相应敞口 |

“先定基差、以后点价”描述定价先后；“先提货、后点价”描述提货与定价先后，两者不能混为一项。暂未提货的基差合同也可能先锁基差后点价。
“01/11”不构成完整合约身份，要登记年份；主力、近月不是永远固定的参照对象。确认合同究竟以成交价、结算价、区间均价还是其他机制执行点价，以及由谁点、最后何时点、未点如何处理。

数字练习：
- 基差固定+20，目标货价不超过2700（同口径、未含新增费用），点价上限为2680。
- 点到2678，公式货价2698；若另有运费50，到厂现金报价为2748，税费仍需按约定拆解。
- 未锁基差时，期货2640+新报价60=2700；期货2678+20=2698。期货更低不必然意味着最终现货更便宜。
- 若已经签订+20的有效合同，后来的市场报价+60不自动修改原约定；看合同效力、期限和履约条件。

## 3. 必须修正的交易推论

### 3.1 高价点货后做空，并不保证弥补成本劣势

录音的“2800点价、+20买货，再做空等回归”只能作为情景，不能作为必赚方法。
设采购2820，期货卖开2800，未来现货售价S、期货买平F，则等量匹配、同单位下：

期现合并毛损益/吨 = S − 2820 + 2800 − F = (S − F) − 20。

因此，若最后销售基差仍为+20，毛损益为0；若为−10，毛损益为−30。还须扣费用。
期货回落带来的空头盈利可能同时伴随现货售价下降；既有销售固定价/浮动价和基差约定必须一并核算。
期货也可能先涨到3000、3400带来保证金压力，或在点价期限内不回落。基差变化可以由期货或现货任一边完成，不意味着期货必跌、必在30天内回归。
采购未定价与已定价持货的风险方向也不同：未定价采购通常有价格上涨成本风险；已固定采购成本、未定价销售的库存有价格下跌风险。具体套保须先列两端定价状态与净敞口。

### 3.2 分清套保、基差交易与方向性交易

在台账上写出每笔期货委托目的、对应合同/批次、数量和退出条件。
“通过盘面优化利润”“套利”是录音中的业务称呼，不能据此推断低风险或确定盈利；多做一笔超出对应敞口的期货交易可能增加方向风险。
一笔现货利润很薄或“5—10元/吨”是录音案例经验，不是当前市场的固定利润。

## 4. 每日数据与区域物流

行情表至少记录：日期/发布时间、数据来源、地区/品牌/质量、交货口径、含税与否、价格/报价或成交性质、完整期货合约、同步期货价格、基差、成交量/持仓量、事件备注。
合同月均价另列来源、纳入日期、缺报价日处理、算术或数量加权方法、累计均价及最终结算均价；月中累计值标为“暂定”，不能当最终价。
月初2721到最终均价2714差7，仅说明两个统计值相差7，不说明月内最高最低差、日变化或波动率小。教材分别算首末差、最高最低差、均价和日变化。
持仓少/成交少可能使图线平，但不保证价格风险小；另检查买卖价差、盘口深度、成交和退出能力。流动性与波动率是不同指标。

建立“品牌 → 实际签约主体 → 具体工厂/提货地 → 质量规格 → 下游地点 → 运输路线 → 到厂成本”表。录音中的品牌、分厂归属和区域名单作为待核查线索，不作为全国完整分布。
铁路与汽运比较要使用同路线同批量的全程报价：短倒、装卸、装箱、干线、目的地配送、损耗、时间及资金。不能一概认定铁路更贵或更便宜，也不固定每包重量、每箱包数。
普通现货库存、指定交割库库存、可交割品和有效标准仓单分栏；在交割库里不自动成为仓单。在盘面卖出成交不自动完成实物交割，后者另有资格、品牌、仓单、时间和配对规则。

## 5. 承兑、账期与税费预算

### 承兑与现金流

登记付款中现金和承兑比例、票据类别/承兑人、到期日、实际收到日期、贴现条件、费用和最终可用现金日期。
“收到承兑”不等于“收到可立即支用且无成本的现金”。资金成本按垫款到回收/变现的实际时点分段计算；贴现和资金成本避免重复计同一期间。
报价2890若附长账期和承兑，不可直接与即时现汇2890视为同等收益。

### 税费练习的边界与算法

税率按交易实质、纳税人和适用计税规则核实；不采用“所有货物都是13%”。
一般计税、进项可抵扣的练习，含税金额P、税率r：
- 不含税金额=P/(1+r)；
- 税额=P−P/(1+r)。

纯教学假设：运输采购含税50、按9%取得可抵扣凭证；销售整体按13%计税，并在销售含税金额中仅用50覆盖这段运输。
- 不含税运费成本50/1.09≈45.87；
- 对应不含税销售收入50/1.13≈44.25；
- 该部分不含税毛利约−1.62。
- 若仅需覆盖此不含税运费成本，含13%的对应销售金额应为(50/1.09)×1.13≈51.83；补价约1.83，而非无条件50×4%=2。

这两个数字对应“同含税收支下的利润差”和“覆盖成本需要的含税补价”，不能混用。未考虑附加税费、所得税、其他成本和抵扣时间。
货与运输是一项带主附关系的交易还是两项交易，须按实际业务确定；不能为了税率随意调货价/运费、拆票或合票。预算要区分含税资金收支与不含税毛利，进销税率相同不表示税额自动相抵。

## 6. 真实完成单复盘与台账练习

待取得一笔脱敏完成单后，逐项关联：
采购合同/价格来源 → 提货与收付款 → 销售合同及点价记录 → 期货卖开成交 → 期货买平成交 → 双边结算与发票 → 期现合并损益/现金流。
所有阶段按真实时间排序，记录实际成交而非仅委托价；不能从盈利结果倒推当时决策必然正确。

目前先用模拟材料建空白字段，不臆造公司真实成交。完成单最小材料：买卖合同条款、日期/数量/地区/规格、点价机制、收付记录、运输/仓储、票据和税率、期货逐笔成交/手续费、实提结算、预算与实际差异；可隐藏对手身份。
业务合同台账、期货成交台账、行情跟踪表分表，通过合同号/批次/套保编号连接，避免把日行情直接当结算凭据。
